## 2. 指标定义

### 2.1 对局分类

按"对战提交时刻"角色判定，**一类与二类互斥**（种子优先）：

| 分类 | 定义 |
|------|------|
| **一类对战** | 提交时**一方是候选**（且无种子参与）。 |
| **二类对战** | 提交时**一方是正式种子**。 |
| **三类对战** | 所有对战结束后，**双方都不是正式种子**（"白打"对局，浪费的计算量；按最终时刻判定，可能与一类有交集）。 |
| **有效对战数** | = **总对战数 − 三类对战数**。 |
| **总对战数** | 二分种子方案实际执行的全部对战局数。 |

### 2.2 候选与节省

| 指标 | 定义 |
|------|------|
| **累计候选个体数** | 曾被启动过的候选个体数（去重，同一个体被重复选为候选只算一次）。 |
| **节省率** | `1 − 总对战数 / RR 对战数`。 |
| **Fallback** | 累计 12 个候选失败 → 直接用 TrueSkill 排序取 Top16 的兜底机制是否触发。 |

### 2.3 覆盖率

| 指标 | 公式 |
|------|------|
| **Top16 重叠率 vs GT** | `\|二分Top16 ∩ GT Top16\| / 16` |
| **Recall@8** | `\|二分Top16 ∩ GT Top8\| / 8` |
| **Recall@16** | `\|二分Top16 ∩ GT Top16\| / 16`（与 Top16 重叠率等价） |

## 9. 关键观察（仅基于本次原始数据）

### 9.1 计算规模

- **总对战数** = 706.58 ± 33.05，相对全量 RR（12640）节省 **94.41% ± 0.26%**
- **二类对战占主体**：528.24 / 706.58 ≈ **74.8%**（种子 vs 全体的批量阶段）
- **一类对战**：178.20 / 706.58 ≈ **25.2%**（候选甄别成本）
- **三类对战**（白打）：76.51 / 706.58 ≈ **10.8%**（双方最终都不是种子）
- **有效对战数**：630.07，std 仅 12.86，**结构非常稳定**
- **0% fallback 触发率**（45/45 全部成功凑齐 3 个种子）
- **平均 5.58 个候选**完成 3 种子选拔，最少 3 个，最多 10 个

### 9.2 覆盖率

| 分布 | Top16 重叠率 | 评价 |
|------|:---:|:---:|
| **uniform** | **0.7500** | ✅ 良好 |
| **normal** | **0.7917** | ✅ 良好 |
| **bimodal** | **0.3292** | ⚠️ **不达标** |

- **uniform/normal 平均 Top16 重叠率 ≈ 0.77**，Recall@8 ≈ 0.875，可接受
- **bimodal 平均 Top16 重叠率仅 0.33**，Recall@8 仅 0.33，**明显偏低**
  - 最差场景（bimodal_constant_s342, bimodal_proportional_s342）Top16 重叠率仅 0.125
  - 最好场景（bimodal_constant_s242 等）也只有 0.50
- **q 模式影响相对较小**：constant ≈ proportional ≈ random，差异在 0.04 以内

## 10. 结论

### 10.1 计算规模 ✅ 完全符合预期

- 节省率 94.41%，比 RR 减少 17.9× 计算量
- 0% fallback 率，方案在 45 组场景下都能稳定收敛到 3 个种子
- 二类对战（种子 vs 全体）占 75%，符合算法的设计意图

### 10.2 覆盖率 ⚠️ 强分布依赖

- **uniform / normal 下覆盖率良好**（Top16 重叠 ~0.77，Recall@8 ~0.88）
- **bimodal 下覆盖率不达标**（Top16 重叠 ~0.33），需考虑算法层面的改进
  （如放宽中位区间为 Top25%-Top75%，或先检测分布形态）

### 10.3 参数选择验证

当前参数（M=32, n_battle=2）相对 v2 (M=16, n_battle=1)：
- 计算量增加约 1.58 倍
- uniform/normal 上 Recall@8 从 ~0.76 提升到 ~0.88
- bimodal 上几乎无改善（说明 bimodal 的失败是结构性而非估计精度问题）

参数选择**对 uniform/normal 是值得的**，但若实际生产中以 bimodal 分布为主，则需另寻改进路径。
