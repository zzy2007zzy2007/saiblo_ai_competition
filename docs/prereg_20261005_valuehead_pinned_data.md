# 预注册：**候选 Q —— 用"随机钉类采到的有塔数据"重训价值头**

> 2026-10-05 12:4x 写（**在跑这批数据之前**）。背景与依据：
> * **用户 2026-10-05 提议**：自对弈没有"有塔状态" ⇒ 用**随机钉类**（`--class-pin-random-prob`）解决。
>   该机制当年只写到计划（`docs/az_posnet_random_class_plan.md` §5），**今天按计划落地**并实测：
>   **`己方有塔` 样本 0.0% → 57.2%**（8 局冒烟；工具 `code/test_match/check_tower_coverage.py`）。
> * **为什么值得**：判据里的局面是 `rule_v4` **每局建 16.5 座塔**，而我们此前的训练数据
>   **一个塔局面都没有** ⇒ 价值头（= 搜索的排序引擎）**从没在它真正要面对的局面分布上训过**。
> * ⚠️ **性质**：这是**方法层**实验（换训练数据分布），**不是**配置修复；
>   目标来自**我们自己的对局结果**，**不模仿任何对手**（禁令见任务章程 §2）。
>   部署侧**照旧**（`az_bridge_ai.py` 不暴露该开关 ⇒ 判据读数不受采集影响）。

## 1. 臂

| | ckpt | 说明 |
|---|---|---|
| **对照 Q0 = A1** | `posnet_A_k5_m32.pt` | A1 配置的 seed `7..22` 前缀读数 = **0.5000**（验收 0.5312）|
| **臂 Q1** | `training_history/vprior/posnet_Q1_valpin.pt` | 用**随机钉类 p=0.02 采的 100 局**（tag `PIN002_collect100`）建价值缓存 → 只重训 `value_state`（`--label-mode terminal --freeze-bn --epochs 4 --lr 3e-4`，与 V2 同口径）|

- 训练必须用 `--ckpt training_history/vprior/posnet_A_k5_m32.pt` ⇒ **`class_state`/`pos_state` 逐位不动**；
- 训练器自带"按 val MSE 取最佳"的早停 ⇒ 若新数据**不比初始权重更好**，产物会与对照**逐位相同**
  （V1/V2 都出现过，**那时本臂按构造为 null，必须如实记档**）。

## 2. 样本量与判据（**先写死**）

- **快读数** = seed `7..22`（16 对 = **32 局**），A1 配置（`ITERS=256 DEPTH=4 K=24 SM=15 MODE=pos-only SKIP1=1`），`--jobs=8`；
- **验收** = seed `7..70`（128 局），**只在快读数达标时跑**；
- **晋级**：`p̂ ≥ 0.55`（对照 +5pp）或 `≥ 0.70`；
- 有效性门槛同前（`verdict=engine`、`illegal=0`、无 INVALID、`terminal=True`；无效+缺失 >10% ⇒ 作废）；
- **禁止**看数据后改样本量/seed/只报子集；**没有**延长规则。

## 3. 预注册的预测

- **P-Q1（数据侧的硬读数）**：新数据的 `己方有塔` 样本比例应 **≥ 30%**（旧数据是 **0.0%**）。
  若它仍然≈0 ⇒ 采集没生效，**实验作废**、先查代码。
- **P-Q2（数值）**：`p̂ ∈ [0.45, 0.65]`（方向未知：更贴判据分布**可能**更准，也可能因为
  "训练数据来自被扰动过的自对弈"而引入偏差）。
- **P-Q3（机制旁证，必须报）**：我方闪电次数/出招回合数/建塔数应与 A1 几乎一致
  （部署没变）；若建塔数明显变化 ⇒ 说明改动漏进了部署路径，要查。

## 4. 判定与后续

1. `p̂ ≥ 0.55` ⇒ 跑 128 局验收；`≥0.70` ⇒ 走机械门（独立验证 + 记档 + 用户确认）。
2. `0.45 < p̂ < 0.55` ⇒ 记"**换成有塔数据重训价值头在本判据下测不到增益**"（进寄存器）。
3. `p̂ ≤ 0.45` ⇒ 记"有害"，并检查"被扰动的自对弈"是否把价值目标整体带偏。
4. 无论结果：**下一步**都可以考虑"**判据分布内的数据**"——即在**对 `rule_v4` 的对局**里
   记录 (observation, 终局) 交给价值头（我方 bridge 已经有影子状态，能算终局标签），
   并且可以在那些对局里也开随机钉类。那要另写实现计划 + 预注册。

## 5. 成本

采集 100 局 ≈ **50 min**（8 workers）；建缓存 ≈1 min；训练 4 epoch ≈ 2–5 min；
快读数 ≈ 8–10 min。合计 ≈ **1 h**。
