### 4.3 **深度学习在其中扮演什么角色**（一句话版）

> **深度学习在现役系统里只做两件事：(a) 提供一个"位置先验"，决定 24~160 个候选里先看哪些格；(b) 提供一个"价值标量"，给 rollout 的叶子打分。**
> **它不决定"选哪个类"**（那是 MC 安静模拟裁决的），**不决定"何时出手"**（那是 skip1/HOLD 逻辑与搜索），**不产生训练闭环**（没有 on-policy 自对弈在跑，最后一次自对弈迭代是 2026-08 且被诊断坍缩）。

证据：
- 类的裁决路径 = `mc_quiet` 根节点仲裁（`state_of_play:30-31`、`milestone:33-35`）；把仲裁关掉整张网只值 **0.0312**（`a731b89`）。
- 类头本身被证明**是常数函数**（跨局面 std 中位 0.024，`state_of_play:62`），且部署时**只被用 argmax**（`final_report:54`）。
- 位置先验的**真实信息量**：亚军走法 recall@24 = 92.8%，但按动作拆开后**只有闪电有信息**（67.3% vs 随机 8.9%）、**建塔 @24 = 74.9% 与随机 75.0% 持平**（`prior_ceiling:8-27`）。
- 价值网的语义是"**16 步 rollout 后的期望**"或"整局终值"，被 RL 调研判为"**给浅层 leaf 打分是语义错位**"（`rl_survey/00_summary.md:76`）。

## §7 三个结论（给负责人）

### 7.1 历史上"深度学习类方法"实际带来了多少**可验证的**收益？

**答：很少，而且全部集中在 2026-09-18~09-20 的那三天。**

- **可验证的正收益只有 3 个效应，全部发生在 2026-09-18~09-20**：
  ① **C1a 推理期**把搜索的 rollout 排序换成价值网一次前向（**零训练**）：20.3%→39.1%；
  ② **C1b 价值偏好位置网**（训练）：21.1%→35.2%，256 局复核 18.4%→42.2%；
  ③ **C2 只换价值网**（训练）：18.4%→32.4%（+14.1pp，p=0.0003）。
  ⚠️ 三者严格说都是"**用已有的价值网/它的排序**"，**没有一个**来自新的学习范式。
- **另有 1 条"网络差异"配对显著**：`UNBAN_A` **+17.19pp（p=0.0032）**，但它是**内部 A/B**（对手 = 冻结最好版），且前提是**允许闪电**。更关键的是同一张老网**禁闪电只有 0.3359（−34.38pp）** ⇒ **这一条网络差异的收益完全依赖制度**，不能读成"这张网更好"（`8f5e1fc`）。
- **除此之外，8 条动作网重训路线全部为负或中性**（`cda8fc8`：−11.7 / −15.6 / 1.00% / 47% / −7.8 / −10.2 / **−43.0** / −18.0）。
- **"拟合变好"与"棋力变强"在历史上从不相关**：离线 recall @24 93.9 vs 94.4、Spearman −0.11→+0.428、留出 @24 80.4%→85.1%、实体 Transformer R² 0.9969、低质量价值网 R² 0.4708——**这五次改进全部对应实战不动或更差**（`prior_ceiling:111-119,235-249`；`prior_repair:204-217`；`checkpoints.md:258`）。
- **唯一一次端到端 RL（P3 的 AZ）**：自对弈相对指标 50%→68.8%，但对 rule_v4 只到 31.2%，并被诊断为**特征表征坍缩**（`eeebd19`）。
- 对照：**工程修复一条就 +49.2pp**（A1），**搜索评估器一换就 +23.5pp vs rule_v4 / +86% 内部**（B5）。**深度学习的全部历史收益加起来小于这两条中的任何一条。**

### 7.2 目前**最强的确定性增益来源**是什么？

**排序（按"有重复读数 + 机制清楚"）：**

1. **工程/引擎级修复**：薄搜索 +49.2pp、MC 仲裁 0 保护 +64.9pp（a731b89）、C++ 引擎 8.7× 让搜索量成为可能、`int("op")` 一行 bug 让一个动作类恢复了通路。
2. **搜索 + 评估器的结构与预算**：k 从 1→24（0.0938→0.6562）、k=160 vs k=1（100%/+26.7hp）、**扁平 rollout 取代树搜索（86%，且更便宜）**、`MC_HORIZON` 256→128（0.891→0.984）、**降 k + 大采样（64.1%，+5.08hp 显著）**。
3. **"用模拟裁决"而不是"用学习裁决"**：M6b/M6c-ROOT 的 `mc_quiet` 根节点仲裁（+13.3pp，零手写规则，过独立验证）。
4. **调参/配置**：座位、种子、`FLAT_SEED`、`MC_EVERY`、`MC_CELLS` 这些"看起来像调参"的旋钮，量级可达 10~27pp（但**必须按座位拆分 + 固定种子 + 未见样本复核**，否则就是 winner's curse）。
5. **最后才是网络**：位置先验的信息量经测量**已经很低**（建塔 @24 = 随机、只有闪电 7.5× 随机，`prior_ceiling:8-27`）。

### 7.3 若要做深度学习方向，**哪条路已证明走不通、哪条只是没做完**？

**A. 已证明走不通（有判据、有机制、且**多方向重复**）：**

| 走不通的路 | 判死的证据 |
|---|---|
| **用"搜索的输出"当监督目标来重训策略网（自蒸馏）** | 蒸分布 −43.0pp、蒸 rank-1 −18.0pp、topk 目标 −10.2pp、TEMP=1.0 −20.3pp；机制：搜索的候选集每次重采（集合只 1/12 相同），目标不可复现；且图的先验来自**官方 SDK 的独立信息源**，换成自己搜索的投影 = **净信息损失** |
| **用"近视叶评估"当教师**（安静 rollout / 1-ply 价值） | A② −15.6pp、r1 配方 −7.8pp，两次都是"学生比教师更忠实反而更弱" |
| **用规则/启发式分数蒸馏替代部署先验** | 拼接蒸馏网 k=24 **12.5%**，两轮都败（`prior_repair:105-141`） |
| **把价值网当"裁判"（替代 rollout 打分）** | rollout 0.9375 vs 搜索值网 **0.2031**（`097ded8`）——角色分离被明确证明 |
| **端到端 RL / 从零不要搜索** | 无搜索的起点只有 **0.0938**，要补 ~60pp；`final_report:128-132` 据此**关闭 A 选项**；RL 调研独立算出追平 KataGo 主 run 需 **≈146 个月**（`rl_survey:73`） |
| **reward shaping（攒金币类）** | 文献层：potential-based shaping "安全与无用是一体两面"，不能用它教新东西；项目层：`Φ_gold(终局)≠0` 会让"攒钱"成为最优（`rl_survey:52-54`） |
| **靠加数据/加参数解决信用分配** | 数据量曲线**平坦**（14 局 +0.036 / 28 局 +0.040 / 39 局 +0.045）；"缺的是**信用信号**不是数据"（`final_report:133-134`）；80 局曲线平坦 + 60 epoch 过拟合（`prior_ceiling:108-109`） |

**B. 只是没做完（有机制理由、但缺一次干净的量尺）：**

| 没做完的路 | 现状 | 卡在哪 |
|---|---|---|
| **动作头 factorized / autoregressive（顺序化 + 每步重算 mask）** | 只有二手文献结论 + 一个未实现的 idea 文档 | 现有 map+3 头 ≈ 各因子边缘乘积，"表达不了协同"的确切位置是**提案可达性**（`rl_survey:44`）；未做 |
| **Sequential Halving（同预算精度 +5×）** | `rl_survey` 算出 266 候选取 max 的噪声偏差 ≈371 vs 真实分差 71（**5 倍噪声**） | **一次离线验证都没做**（P0 建议、"零对局指标"就能判，1 h 改码 + 30 min） |
| **评估协议（SPRT + 配对 + 座位协变量）** | 已算出"判 5pp 需最坏 3468 局 ≈12.6 h" | 未实现；⚠️**这是"其他一切 A/B 是否可信"的前置** |
| **座位差排查（旋转增强 + 双座位等量采样）** | 座位差量到 **27pp（≈355 Elo）**，且 P1 能看到 P0 出招 | 未做；`rl_survey:113` 列为 P1 |
| **搜索评估用 Φ=V（把血量/值网放进评估函数）** | C 线结论"唯一有效位置是搜索的评估函数" | 需改搜索；未做 |
| **用"多采样随机化 rollout 均值"当教师（只在小 k 下才跑得动）** | 已证明 N_eff=15 时"大采样"被截断（M1 事故），k=48+N64 才有真 N=64 | 未在充足采样下重做蒸馏；但**离线 recall 与实战已三次脱钩**，优先级低 |
| **实体 Transformer / 更大价值网进部署链** | 拟合已到 R² 0.9969，但**从未接入** `AntWarNetwork` 体系（`entity_value_128_reduced.pt` 训练未过 tanh，要设 `AZAI_VALUE_TANH=0`） | 未做；且 C5 的用途本写为"复刻亚军价值，不是更强" |

**给负责人的一句建议（有证据支撑、不是空话）**：
> 先把**测量的可信度**解决（SPRT + 固定种子 + 座位拆分 + 未见样本），再花算力。历史上**两次** +11.1pp/+4.7pp 的"正读数"在未见样本上翻成 −9.4pp/−18.8pp（`final_report:70-74`），而**内部显著为正的 +5.08hp 对外 0 传导**（`prior_repair:582-600`）。在现有协议下，**任何 <10pp 的改进都不可判**（`rl_survey:126`）。
