# 价值网"注意力"分析 + 三个可操作落点

> 状态：**记录 + 可操作结论**。详表见 `docs/value_net_attention_20261031.md`（commit fe88ba9），本文件只留核心结论与落点。

## 0. 一句话

价值网不是"只会抄血量差"，但很浅：**血靠抄 `hp_delta` 捷径、金币是真读但小 ~60 倍、塔两条通路互相打架、冷却几乎不敏感、全线性无分段**（42 维线性模型 R²=0.933）。

## 1. 核心发现（三个"注意力"）

| 量 | 读法 | 量级 |
|---|---|---|
| **血量** | **抄捷径**：我方血 −20 走 `hp_delta`(stats[1]) → −13.33 HP（占 99.2%），走正规 `base_hp/50` → −0.11 HP（0.8%）；且 `base_hp[enemy]` 梯度符号是反的 | 12.62 HP / +20 HP |
| **金币** | **真读**：三条编码（`coins/300`/`safe_coin`/`coin_ratio`）同一个价、近似可加 | +90 币 ≈ 0.19 HP（自洽 0.38） |
| **塔** | **两路打架**：stats 侧"塔数+1 且等级和+1" = +1.24 HP；board 侧"真放一座 1 级塔" = **−0.10 HP** ⇒ 符号相反、差 1.3 HP | 1.24 HP（stats） |
| **冷却** | 几乎不敏感 | "冷却→立即好" = +0.12 HP |

**线性探针**：`V ~ 42维 stats` 的纯线性 R² = **0.9331** ⇒ 无交互、无分段，坐实"没有 90 折点"。

**汇率**：值网自己的汇率 ≈ **1 HP = 148 金币**（标签的 1/20 V 汇率它只学到 63%）。

## 2. 三个可操作落点

### ① 编码器归一化（便宜）
`|梯度|` 榜前 3 名是 `coin_ratio`(12.28)、`safe_coin`(11.07)、`hp_delta`(9.42)——全是**没归一化**的维，`coin_ratio`+`safe_coin` 吃掉 stats 内 50.4%，而归一化的 `coins/300` 只有 0.9%。
⇒ "值网最敏感的是金币"有一半是编码器没归一化造成的假象。归一化这些维，能消除假敏感、让真实信号浮出来。

### ② 用 rel / kgeo 标签削掉 hp_delta 捷径（用户补充：kgeo 也能削）
值网抄的是 `hp_delta`（stats[1]）这个**现成的当前血差**，因为 terminal 标签就是终局血差、和它同源。
- **`rel` 标签**（`abs − d_t`）：把当前血差从标签里减掉 ⇒ 相关 −0.24，**彻底削掉捷径**；
- **`kgeo` 标签**（`w_k = k·γᵏ`，`w_0=0`）：当前帧权重为 0 ⇒ 相关 0.863（对比 `geo` 的 0.937），**部分削掉捷径**。
⇒ 两者都比 terminal / geo 更"逼"值网去学金币/塔/冷却这些非捷径量。这正是重训 P1 四臂里 `rel+kgeo` 那臂的理论依据。

### ③ 塔两路打架（stats vs board 符号相反）
stats 侧说"塔越多越好"（+1.24 HP），board 侧说"放塔掉分"（−0.10 HP）。
⇒ 根子还是训练分布"有塔局面 0%"：值网从没在"真放了塔"的局面上被认真教过塔的价值。换数据（注入采集）后应能缓解。

## 3. 对值网重训的直接启示

```
· 重训计划（docs/value_net_retrain_collection_plan_20261031.md）的 P1 四臂里，
  rel+kgeo 那臂 = 落点②，正好是"削捷径"的主力
· 落点①（归一化）是编码器级小改动，可与重训并行/之后做
· 落点③（塔打架）靠"换数据"解决，不必单独动
⇒ 这次注意力分析把"值网为什么不行"从行为层拆到了"它在看什么"，

```

## 4. 一个必须记住的方法论坑

`|grad|×std` 线性外推会给出**不可能的值**（`safe_coin` 上 2.81 V，而 V 的 std 只有 0.63 V）⇒ 一律用**实测有限差分**。另外 13/42 维 stats + 8/28 通道在这批局面里恒定（没人升级），`|grad|` 非零但实际影响为 0——`|grad|` 榜前 6 名里有 2 个就是这种，别被梯度榜误导。
