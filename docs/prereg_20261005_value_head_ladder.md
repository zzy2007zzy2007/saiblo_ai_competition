## 2. 样本量与判据（**先写死**）

- **快读数** = seed 前缀 `7..22`（16 对 = **32 局**），在**选出的配置**下跑，`--jobs=8`；
- **验收** = seed `7..70`（64 对 = 128 局），**只在快读数达标时跑**；
- **主读数** = `code/test_match/analyze_paired.py` 的配对分 `p̂`；
- **晋级规则**（满足任一）：`p̂ ≥ V0 同前缀 p̂ + 0.10`；或 `p̂ ≥ 0.70`；
- **有效性门槛**：同 `prereg_20261005_baseline_vs_rulev4_128.md` §4（`verdict=engine`、`illegal=0`、
  无 INVALID、`terminal=True`；无效+缺失 >10% ⇒ 该批作废）。
- **禁止**：看数据后改样本量、改 seed、只报子集。**没有**延长规则 ⇒ 一次到位。

## 3. 预注册的预测（把它变成真检验）

- **P-V1（低期望，先写死）**：V1（只加曝光）**≤ +5pp**（依据：旧数据上 3 epoch 已把 val MSE
  从 0.05815 压到 0.05581，几乎饱和；且验证集只有 20 局）。
- **P-V2（不确定，给区间）**：V2（换数据）落在 **−5pp ~ +15pp**；我**不**预期它单独跨过 70%
  （价值头只是"1-ply 排序"的天花板，而**位置头还在模仿旧价值头**⇒ 只换价值头会与位置头错配，
  见配方 §7.3/§7.4）。
- ⇒ 因此 **V2 的合理后续**是"价值头 + 位置头一起重训"（配方 §3），但那要**另写**预注册。

## 5. 判定与后续（先写死）

1. **两条都不达标** ⇒ 记档"**换价值头数据/曝光量在本判据下测不到增益**"（进寄存器，标强度），
   下一步转"价值头+位置头同批重训"（需要新预注册）或候选 C（类轴，需要新损失代码）。
2. **任一条达标** ⇒ 跑 128 局验收；**若验收 ≥0.70** ⇒ 走机械门
   （`docs/gate_independent_verification_protocol.md`：无上下文独立验证 + 记档 + 用户确认），
   并在结论里写清"**这是价值头重训带来的**"，同时给**它相对 V0 的增量**。
3. 任何情况下**都不得**把 V2 的结果解释成"位置头也变好了"（位置头逐位未动）。

- 不用 val MSE 当判据（它在本项目已被记为"非泛化读数"，验证集只有 20 局）。
