# 预注册：**rollout 阶梯**（安静 → K 步双向 → 全双向）——"把评价器补成真的"

> 2026-10-06 深夜写（**在跑这批之前**）。章程：`docs/task_ruleV4_90_charter.md`；判据：两段各 128 局都要 ≥90%。
> 用户 2026-10-06 点名方向之一："现在安静 rollout 其实是残缺的 ⇒ 理论上用真实决策会更好"。

## 0. 为什么做这个（三句话）

1. **安静 rollout 有偏是构造性的**：打完候选那一手后**双方都不再出招**，只 `advance_round()`
   ⇒ 它衡量"这一手对基地竞赛的**纯效应**"，**看不见对手反应、看不见我们后续决策、看不见经济-节奏链**
   ——而我们目前全部增益恰恰来自"该不该花钱/花在哪个类"这类**节奏**问题。
2. **"双向真实决策"这条其实从没被测过**：当年贪心 rollout 死掉的原因是
   **bridge 的 300 s 读超时**（8 条证据见 `docs/engine_crash_probe.md`），**不是逻辑错**
   ⇒ 现在有 `MVS_TIMEOUT_SECONDS`（可调）+ 合法性预检 + 截断，条件已具备。
3. **格子级诊断说我们缺一个可信评价器**：经济类上"位置先验 / 价值网"的 top-1 格只落在结果代理的
   **39% / 23%** 百分位（`experiment_log.md` 2026-10-06 21:5x）⇒ 无论把"选类×选格"交给谁，
   都要先有一个**更可信的评价器**。

**性质**：方法层（换**评价**），不引入任何对手动作/人工规则；用户 2026-10-06 起明确"时间很充裕"⇒ 贵一点可以接受。

## 1. 臂（写死；**除 rollout 深度外一切不动**）

| 臂 | rollout 形式 | 说明 |
|---|---|---|
| **R0（对照）** | 安静（现状）| `mc_quiet` + `ROOTONLY`，第一里程碑配置**原样** |
| **R1** | **K=8 双向**：候选打下去后，双方各按当前策略出招 8 回合，之后转安静推进 | 成本 +K×(2 前向+解码) ≈ +0.2 s/候选 |
| **R2** | **K=32 双向**：同上，K=32 | ≈ +0.8 s/候选 |
| **R3** | **全双向贪心**（打到终局；仍需 ≤512 回合 + 合法性预检 + 单决策时间上限）| 只有当 R1/R2 **任一** 在筛选中 ≥ R0 +8pp **且** `dec_max` 可控时才跑 |

- 公共配置：`posnet_A_k5_m32.pt`、`ITERS=256 DEPTH=4 K=24 SAMPLE_MULT=15 MODE=pos-only SKIP1=1`、
  `POSPIN=mc_quiet MC_HORIZON=256 MC_EVERY=5 MC_ROOTONLY=1`。
- rollout 内的策略 = **我们自己的**策略（类头 argmax + 位置图 argmax，含合法性检查）；
  **不得**用 `rule_v4` / 冠亚军的动作（章程反捷径①）。

## 2. 读数与判据

**机制读数（必报，用来决定值不值得继续）**：
- 每手耗时（`dec_max` / `dec_slow`，AI 已埋点）、每局用时（ladder `rc=… min`）；
- rollout **推进了多少回合**、**打到终局的比例**、**候选间分差的分布**（下一轮把埋点补上）；
- 无效/超时局数（`verdict=timeout` 单列）。

**判据（**先写死**）**：
- **筛选（快读数）**：固定段**前缀 seed `7..38`（64 局）**；晋级条件 = **`p̂ ≥ R0 的 p̂ + 8pp`**
  （64 局对 ~12pp 才勉强有分辨力 ⇒ 只当"值不值得上验收"的门槛，**不作结论**）；
- **验收**：晋级的臂跑 **两段各 128 局**（固定段 `7..70` + 随机段 64 seed）⇒ 与 R0 同口径比较；
- **成本闸门**：若某臂单局 > 25 min（8 并行下）导致一次 128 局 > 6 h ⇒ 只跑该臂的 64 局并**记档说明**（不作验收）。
- **⚠️ 单段读数不作结论**（第一里程碑的教训：固定段 0.7344 / 样本外 0.6875）。

## 3. 预测（写下来，事后对照）

- **P-R1**：K=8 双向的**分差会比安静版更"有区分度"**（候选间分差变大）；若分差几乎不变
  ⇒ 说明 8 回合内双方都没做出有影响的事 ⇒ 该继续加大 K 或直接上 R3。
- **P-R2**：K=32 的改善若 ≤ +3pp ⇒ 这条线的**边际收益很低**（"更真实"并不自动更值钱，
  与项目史上"1-ply 价值偏好已复现 oracle 收益 86%"的先例一致）。
- **P-R3**：全双向**很可能**在 8 并行下撞超时（`dec_max` 分钟级）⇒ 需要提 `MVS_TIMEOUT_SECONDS`
  或减少每局决策数；若为跑通而把 K 降回来，等于退回 R1/R2，**不算 R3 的读数**。

## 4. 成本估计（用户 2026-10-06：时间充裕）

| 阶段 | 成本 |
|---|---|
| 机制埋点 + 离线小样（不跑对局）| ~0 |
| R1、R2 各 64 局筛选 | 2 × ~1.5 h（若 K 影响不大）|
| 晋级臂两段验收 | 2 × ~2–3 h |
| R3（若跑到）| 单局可能 >25 min ⇒ 6–10 h/128 局，**按成本闸门只跑 64 局** |

## 5. 判定与后续

- 若 R1/R2 晋级且验收 **≥ R0**（哪怕不显著）⇒ 保留"更真实评价"这件事在配置里的位置，继续加深（K→终局）；
- 若两臂都 **≤ R0 −5pp** ⇒ 记"**更真实的评价在我们这个策略下并不更好**"，
  并把原因写清（内层策略弱 ⇒ 模拟出来的局面不真实）；**这条线转冷**，回到格子级/价值网那条；
- 无论结果：**不动判据、不换 ckpt、不挑段**。
