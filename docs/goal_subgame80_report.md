## 2. 怎么做到的（三步，全部可复核）

1. **S1a 复用已有蒸馏资产**：`distill_data/` = **400 局 / 106,694 决策**，监督 = SDK `ActionCatalog` 评分

   ⇒ **无需为"禁闪电"重采数据**；三头目标相同（与部署端"三头钉同一个类"一致）。
2. **S1b 蒸馏 + 嫁接**：`code/distill/train.py distill_data/ --epochs 30 --lambda-soft 0`

   再用 `code/tools/graft_policy.py` 把蒸馏网装进 `class_state`/`pos_state`（**94/94 键匹配**），
   **`value_state` 保留原网** ⇒ `checkpoints/grafted_sdk_A.pt`。
3. **S1c 评估**：部署配置一字未动（`pos-only + mc_quiet + 宽菜单 MC_UPG=1/MC_TOPK=3`）+ 双方禁闪电。

## 3. 归因（章程②：手写启发式只能当**诊断臂**）

官方 `Ant-Game/AI/ai_example.py`（36 行）自己就是"**SDK 启发式打分 + 跳过第 0 个束、在前 1..7 取最高分**"，
而我们的蒸馏教师**也是**这套打分 ⇒ 所以必须回答"我们赢的是启发式本身，还是我们的管线"：

| 臂 | 策略 | vs example（128 局）| 说明 |
|---|---|---|---|
| `HEUR_H1_skiptop` | **example 那条规则**（跳过第 0 束）| **0.5000**（**64 对全 1-1**；两侧机制读数逐项相同）| 真镜像 ⇒ 确认"H1 ≡ example 自己的策略" |
| `HEUR_H0_argmax` | **忠实教师**（启发式打分的 argmax，≈ 蒸馏目标）| **0.5547** | 教师本身只比 example 好 ~5pp |
| **本方案** | **蒸馏网 + MC 仲裁 + 搜索** | **0.8016 / 0.8047** | **比教师高 +25pp、比 example 规则高 +30pp** |

⇒ **结论不是"把引擎的启发式搬进来"**：教师/对手规则本身都在 0.50–0.55，而完整管线在 0.80。
