# AlphaZero 训练第二轮：加权未来血量差价值标签 + 数据范围拆分

> 目标：修复第一轮训练（az_az0~az_az4）暴露的价值头没训好、策略过拟合旧数据两个问题，重新训练验证。
> 日期：2026-08-07。状态：计划阶段。

## 1. 背景：第一轮训练的综合负结果

第一轮 5 个 batch（50 局，39270 样本）训练后的模型 az_az4，三个测试全部不优于训练前 gen0120_warm：

| 测试 | az_az3（训练后） | 结论 |
|------|----------------|------|
| raw vs raw（36 局） | 50%（18W/18L） | 策略强度无提升 |
| raw vs rule_v4（12 局） | 0% vs 8.3% | 轻微退化（纯闪电化） |
| search vs search（128/深度4，6 局） | 33.3%（2W/4L） | 完整系统落后 |

**训练损失分析**：策略损失正常下降（2.41→1.02）、anchor 稳定收敛（0.044→0.011），**但价值损失横盘**（batch 1 后一直 ~0.045-0.05，RMSE ~0.22 只比"永远预测 0"好一点）——价值头基本没学到东西，而价值头是搜索的天花板，所以搜索没变强。

**两个根因**：

1. **价值标签弱且样本不足**：当前价值目标 = 每局共享同一个终局 hp 差（±0.05~0.75），局内 ~760 个样本全同一个值，相互高度相关。有效独立价值样本 = 50 局（不是 39K）。第 50 回合的位置和终局 +3hp 之间几乎没有可学习的相关性。
2. **策略目标过拟合旧数据**：训练用全部累计数据（batch 4 时 batch 0 的旧数据已训 5 轮×5 epochs=25 epochs），旧目标来自旧模型，重复训练 = 过拟合最弱模型的搜索行为。

## 2. 方案 A：加权未来血量差价值标签

来源：`docs/value_label_future_weighted.md`（2026-07 记录的方案）。

**核心公式**（每帧一个独立标签）：

```
d_i = hp_P0_i - hp_P1_i              （第 i 帧瞬时血量差，P0 视角）
γ = e^{-1/T}                          （T 为时间常数，控制视距）

raw_label_t = Σ_{i≥t} d_i·γ^{i-t} / Σ_{i≥t} γ^{i-t}   （指数加权未来血量差）
label_t     = raw_label_t - d_t                        （相对量：未来优势变化量）
```

- **相对量形式**（推荐）：标签 0 中心、分布对称，预测"从这个位置出发未来优势会变化多少"，当前血量由特征直接提供，网络不必从零反推。与 MCTS 决策逻辑（比较"哪个动作带来更多优势"）对齐。
- **反向递推** O(n) 计算：`suffix_sum_t = d_t + γ·suffix_sum_{t+1}`，`weight_sum_t = 1 + γ·weight_sum_{t+1}`。
- **量纲**：`label_t / HP_SCALE(20)` 与搜索内部价值量纲对齐（搜索 `_terminal_value` 用 `clip(diff/20)`）。
- **视距 T**：和 MCTS 深度匹配。搜索 128 迭代/深度 4 回合（8 层），取 **T=20**（中期视野，半衰期 ~14 回合），做成 `--tau` 参数（默认 20，可切 10/50 对比）。

**关键可行性验证（2026-08-07 已做）**：现有样本的 `stats` 特征包含双方血量——偏移量确认：
- `stats[22+2] = bases[player].hp/50`，`stats[22+3] = bases[enemy].hp/50`（extras 在 42 维 stats 的偏移 22 处，extras 内第 2/3 项）
- 验证：第 0 回合样本 hp=(50,50) ✓；同回合 P0/P1 样本 hp 一致 ✓
- **因此无需重新采集，现有 50 局可直接反推每帧加权标签。**

## 3. 方案 B：数据范围拆分（用户方案）

**问题**：策略目标（visit 分布）来自旧模型、会过时；价值目标（局结果/加权血量）是游戏事实、可积累。

**设计**：

```
policy_pool = 当前 batch 的样本（策略目标最新）
value_pool  = 全部累计样本（含旧 batch，价值事实可积累）

每步：policy_batch ← policy_pool 抽样
      value_batch  ← value_pool 抽样
forward(policy_batch) → 分解 CE + anchor MSE（anchor 也用当前 batch 的记录输出）
forward(value_batch)  → 加权血量标签 MSE
loss = 策略CE + λv·价值MSE + λa·anchor
```

- 策略侧每步 ~7800 个**独立决策**目标（batch_size=32 下足够）
- 价值侧每 epoch 从累计池抽样（有放回），价值头获得 39K 个独立标签

## 4. 实现改动

### 4.1 `az_train.py`（主要改动）

1. **加载时算加权标签**：按 pickle 文件（=一局）分组样本（保持局内顺序），从每帧 `stats` 反推 `d_t`（P0 视角），反向递推得 `label_t`，除以 HP_SCALE。替换原来的 `value_target` 字段（或新增 `value_label`，训练用它）。
2. **双数据池**：`--policy-dir`（当前 batch 数据）与 `--data-dir`（累计数据，价值池）。若只给一个目录则退化为单池（兼容）。
3. **`compute_loss` 改造**：接收 policy_batch + value_batch 两个 batch：
   - policy_batch：分解 CE（类 CE + 位置 CE）+ anchor MSE（记录输出锚定）
   - value_batch：MSE(value, label)
4. **新增参数**：`--tau`（T，默认 20）、`--value-only-latest`（可选，价值池只取最近 N 局）。

### 4.2 `run_az_batches.sh`（配套）

- batch 循环：训练时 `--policy-dir` 指当前 batch 的输出目录（每次采集用独立子目录或按 seed 范围区分），`--data-dir` 指累计目录。
- 数据目录结构调整：当前所有 pkl 混在 `az_selfplay_data` 一个目录。改为每 batch 一个子目录（`az_selfplay_data/batch{k}/`），训练时 policy 指当前 batch 子目录，value 指所有子目录。

### 4.3 无需改动

- `az_selfplay.py`：标签从 stats 反推，采集逻辑不变（不需要存额外字段）。
- `bundle_mcts.py`：不变。

## 5. 参数（初版）

| 参数 | 值 | 说明 |
|------|-----|------|
| T（--tau） | 20 | 加权未来血量差视距，可调 10/50 对比 |
| λ_value | 1.0 | 价值损失权重（标签量纲 /20 后与搜索一致） |
| λ_anchor | 1.0 | 策略锚定 |
| epochs | 5 | 每 batch |
| batch_size | 32 | 策略池；价值池同尺寸 |
| 数据范围 | 策略=当前 batch，价值=全部累计 | 方案 B |

## 6. 验证计划

1. **训练一轮**（用现有 50 局：价值池 50 局、策略池先取最新 10 局），看价值损失是否开始下降（对比第一轮的横盘 ~0.045）
2. **search vs search**（128/深度4，6 局）：训练后 vs 训练前，>50% 为通过
3. **raw vs raw**（24 局）：确认策略没退化
4. 若 T 有影响，对比 T=10/20/50

## 7. 风险

| 风险 | 缓解 |
|------|------|
| 加权标签仍是 hp 级小量，价值头可能学不动 | 除以 HP_SCALE 放大信号；验证价值损失下降 |
| 策略只用当前 batch（10 局）样本偏少 | 策略目标是每决策独立的 7800 个，足够 |
| 旧数据价值目标来自弱模型（陈旧） | 价值事实可积累，量多弥补；必要时价值池限最近 N 局 |
| 双池训练复杂度上升 | 保留单池退化路径（--policy-dir 缺省 = --data-dir） |

## 8. 一句话总结

**第二轮训练 = 价值标签改成指数加权未来血量差（每帧独立、视距 T 可调、旧数据直接用 stats 反推免重采）+ 策略只用当前 batch 而价值用累计数据，目标是把横盘的价值头训起来，让搜索真正变强。**
