# 预注册：**候选 Q2 —— 用"判据分布内"的数据重训价值头**

> 2026-10-05 13:0x 写（**在跑这批数据之前**）。背景：
> * 已实测的缺口：纯自对弈数据 **`己方有塔` = 0.0%**（`V2_collect100` + `check_tower_coverage.py`），
>   而判据里的局面是 `rule_v4` **每局建 16.5 座塔**；随机钉类的自对弈数据能补"己方塔"（57.2%），
>   但**仍然是自对弈的分布**（对手也是我们）。
> * 2026-10-05 新增管线（已冒烟通过）：
>   `az_bridge_ai.py` 的 `AZAI_DUMP_RAW_DIR` 在**对 rule_v4 的真实对局**里边打边追加裸观测
>   （bridge 收尾会硬杀我们 ⇒ 结束时写文件来不及，实测踩过）；
>   `code/my_ai/az_intent/ingest_bridge_dump.py` 用 **ladder 日志的 `RESULT ... base_hp=`** 反推终局标签，
>   产出 `az_selfplay_seed*.pkl`（`train_value_net.py --build-cache-only` 直接能吃）。
>   1 局冒烟：**409 条样本、敌方有塔 84.8%**（我方有塔 0%——A1 下我们本来就不建塔）。
>
> ⚠️ **性质**：方法层（换**训练数据分布**成判据分布），不是配置修复；
> 目标来自**我们自己的对局结果**，**不模仿对手动作**（只用结果当标签）。
> 部署侧**完全不变**（dump 开关与部署无关）。

## 1. 臂

| | ckpt | 说明 |
|---|---|---|
| **对照 Q0 = A1** | `posnet_A_k5_m32.pt` | A1 配置 seed `7..22` 前缀 = **0.5000**（验收 0.5312）|
| **臂 Q2** | `training_history/vprior/posnet_Q2_valrv4.pt` | 用**判据分布数据**（见 §2 的采集批）只重训 `value_state` |

## 2. 采集批（**先写死**）

- **1 批 128 局、A1 配置、开 `AZAI_DUMP_RAW_DIR`**（tag `Q2_collect128`，seeds `7..70` 镜像）。
  * 它**同时是 A1 在 128 局上的重测**（顺带回答"配置修复的读数稳不稳"）；
  * 预期样本量 ≈ 128 × ~400 = **~5 万条**；预期 `敌方有塔` 比例 **> 50%**（冒烟是 84.8%）。
  * ⚠️ **若 `敌方有塔` < 20%** ⇒ 采集没生效，**本实验作废**（先查管线）。
- 建缓存 `--cache training_history/vprior/vcache_q2`；训练 `--label-mode terminal --freeze-bn
  --epochs 4 --lr 3e-4 --ckpt posnet_A_k5_m32.pt`（与 V2/Q1 同口径）。
- 训练器自带按 val MSE 的早停：**若新数据不比初始权重更好，产物会与对照逐位相同**
  ⇒ 那时本臂按构造为 null，**必须如实记档**（V1/V2 都发生过）。

## 3. 样本量与判据（**先写死**）

- **快读数** = seed `7..22`（16 对 = 32 局），A1 配置，`--jobs=8`；
- **验收** = seed `7..70`（128 局），只在快读数达标时跑；
- **晋级**：`p̂ ≥ 0.55` 或 `≥ 0.70`；有效性门槛同前；**没有**延长规则。

## 4. 预注册的预测

- **P-Q2a（数据侧硬读数）**：`敌方有塔` 样本比例 **≥ 50%**（冒烟 84.8%）。
- **P-Q2b（数值）**：`p̂ ∈ [0.45, 0.65]`。**我偏向"小正效应"**：价值头第一次见到判据分布下的
  塔局面；但它只是**排序器**，且 `pos_state`（位置先验）仍来自旧分布 ⇒ 可能被"位置先验与新价值头错配"抵消
  （V2/Q1 的教训）。
- **P-Q2c（机制）**：部署读数不应出现建塔（我们仍只出闪电）；若建塔 > 0 ⇒ 说明有东西漏进了部署路径。

## 5. 判定与后续

1. `p̂ ≥ 0.55` ⇒ 128 局验收；`≥0.70` ⇒ 走机械门（独立验证 + 记档 + 用户确认）。
2. 不达标 ⇒ 记"**换到判据分布的数据重训价值头，在本判据下测不到增益**"（进寄存器），
   并考虑把**位置头**也放到判据分布上重训（要 `collect_value_prior` 的搜索版/随机钉类版，另写计划）。
3. **无论结果**：这套管线（dump → ingest → 训练）应当**默认打开**跑后续所有测量批
   —— 测量批同时积累判据分布数据，边际成本只有磁盘（~8 MB/局）。

## 6. 成本

采集 128 局 ≈ **30 min**（A1 速度 1.8 min/局、8 并行，dump 只有少量 IO）；
ingest + 建缓存 + 训练 ≈ **6 min**；快读数 ≈ **10 min**。合计 ≈ **45 min**。
