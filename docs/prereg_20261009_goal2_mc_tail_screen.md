# 预注册：**`MC_TAIL` 截断补尾的筛查矩阵**（效率优先；胜率只作副判据）

> 真实日期 **2026-10-09**（第 66 轮写，**在跑这批之前**）。上位目标 `goal-2600a56a`。
> 关联：`docs/goal2_vs_baseline_report.md` §8b（链 C）、`docs/experiment_log.md` §65（`MC_TAIL` 实现与验证）。

## 0. 已知事实（决定本预注册的形状）

| 事实 | 数值 | 含义 |
|---|---|---|
| 安静 rollout **实际长度**（开局）| **245 回合**才到真终局（上限 256 几乎卡满）| "推到终局"是真的；`MC_HORIZON=512` 与 256 读数完全相同是因为**上限基本没被触到** |
| **截断**（128/64/32）后的值 | 退化成 **±0.1 的 HP 粗粒度**（HP_SCALE 归一）| **不补尾 = 毁信号** ⇒ 补尾是截断方案的必要条件 |
| 补尾开启后的值 | 由价值网决定（同局面 **−0.85 vs +0.1**）| **可用性 100% 取决于尾部网质量** |
| 耗时（单次 rollout）| 256 回合 **0.98 s** ▸ 32 回合 **0.20 s**（≈5×）| 效率收益是真的 |
| `MC_TAIL` 实现 | `AZAI_MC_TAIL=value` + `AZAI_MC_TAIL_MIX`（默认全关 ⇒ 旧行为**逐位不变**，已实测）| 可直接筛查 |
| 价值网前史 | 标签轴被扫过，收益**小且噪声主导**（见 `docs/goal2_value_label_prior_art.md`）| ⇒ **不指望涨分** |

## 1. 假设与判据（**先写死**）

- **主假设（效率）**：`MC_HORIZON=64` + 补尾，能把**每局机时**降到 `MC_HORIZON=256` 的 **≤ 40%**，而 32 对筛查胜率的**下降 ≤ 2pp**。
- **副假设（胜率）**：补尾开启后，`HORIZON=64/32` 的筛查胜率**不低于**同等 horizon 的**无尾**版本（即：补尾确实在**救回**被截断毁掉的信号）。
- **判词**：
  - 两条都满足 ⇒ 记"**高效裁判可用**"，并把 C1（路 C）的**完整判据臂**改成用该配置跑（这是本实验的**真正用途**）；
  - 主满足、副不满足 ⇒ 记"省时间但掉分"，只有在"完整判据跑不起"时才降级使用，并如实标注；
  - 主不满足（没省下来）⇒ 记"该实现没带来实质节省"。

## 2. 臂（写死；全部 `MC1` 口径、`opp=example`、seed `7..38`（32 对）、`jobs=4`）

| 臂 | `MC_HORIZON` | `AZAI_MC_TAIL` | `AZAI_MC_TAIL_MIX` |
|---|---|---|---|
| **T256**（对照，= 现状）| 256 | 关 | — |
| **T128** | 128 | 关 | — |
| **T64** | 64 | 关 | — |
| **T32** | 32 | 关 | — |
| **T64V** | 64 | `value` | 1.0 |
| **T32V** | 32 | `value` | 1.0 |
| **T64M** | 64 | `value` | 0.5 |

- 每臂必报：**min/局**、`p̂`（32 对）、无效+缺失、执先/执后拆分、机制（建/降/升/有操作回合）。
- 冒烟闸门照旧（建塔 ≤0.5/局 判退化则跳过）。全部只跑**筛查尺度**，**不构成任何成功声明**。

## 3. 预测（先写死，事后对照）

- **P-T1**：无尾截断（T128/T64/T32）的 `p̂` **随 horizon 缩短而下降**（因为值退化成 ±0.1）——若反而持平 ⇒ 说明"截断处的 HP 差"其实够用（会推翻我对"必须补尾"的判断）。
- **P-T2**：`T64V` 的 `p̂` **≥ T64**（补尾救回信号）；`T32V ≥ T32`。
- **P-T3**：`T64V` 的 min/局 **≤ T256 的 45%**。
- **P-T4**：`T64V` 与 `T256` 的 `p̂` 差 **在 ±4pp 内**（即"效率换来的代价可接受"）。

## 4. 成本与边界

- 7 臂 × 32 对（64 局）≈ 7 × 40 min ≈ **4.7 h**（`jobs=4`；若与其它链并行须遵守"总对局 ≤8"的内存规则）。
- **不改**判据 / seed / 引擎 / 镜像 / 冻结基线；**不训练**任何策略；价值网只用作"截断处补尾"与"叶评估"两条已知通道。
- 结论**不用于**宣称达标；它只决定"路 C 的完整判据能不能跑得起"。
