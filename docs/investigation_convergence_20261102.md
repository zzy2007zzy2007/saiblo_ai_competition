# 调查收敛总结：值网/统一搜索的病根（2026-11-02）

> 把这一长串调查（值网注意力 → 统一搜索根因 → 三结构实验 → Q 网络诊断）收敛成一条清晰的因果链，并严格区分"确定的事实"和"推测的假说"。

## 一、确定的事实（不含推测）

1. **闪电 >> 建塔/升级**：Q 网络 4 个标签臂一致学到 `∂Q/∂闪电 = +0.032~+0.091`、100% 正、平均名次第 1。这是从"闪电很强"这个事实直接推出的，不含推测。
2. **经济平衡病**：钱在 45-89 区间被升级吃掉 69% 收入，96.2% 决策时金币<90，导致"买不起闪电"（不是"不想放"）。这是逐币账本 + 金币×选择对齐的实测结果。
3. **统一搜索打不过 pin**：shape_pin（改 s1 选组）、lightning（改 s2 随机动作）、noupg（删升级候选）三个结构改动全都更差（1W-15L / 0W-16L / 0W-16L），说明瓶颈不在候选结构/随机动作/升级挤占。
4. **值网和动作价值网都长不出"金币×冷却"的条件**：值网 `V(s)`（只吃局面）和 Q 网络 `Q(s,a)`（吃局面+动作）都没有 90 币折点、冷却分层。

## 二、推测的假说（可能是、也可能不是真实规律）

1. **"90 折点"**：金币价值在 90 处突变——这是人工按"闪电花 90 币"的游戏规则推理的，未证实。值网/ Q 网络都没长出它，但**这可能不是失败**（假说本身可能不对）。
2. **"花钱挤占放闪电"的金币×冷却条件经济学**：同上，是人工推理的，未证实。
3. **"16 回合 horizon 错配"**：已被纠正——值网训的是长期（终局血差回归）、用的也是长期（叶子处 bootstrap 到终局），不是 horizon 截断；真正的问题是值网训练质量 + rollout 随机策略失真。

## 三、病根定位（按"确定/推测"分层）

- **表层病（架构）**：值网 `V(s)` 不吃动作，丢了"闪电最值钱"这块（Q 网络喂动作后回归 r +0.066，闪电偏导为正）。
- **深层病（标签/监督）**：terminal 标签一局一值（对"花钱 vs 攒钱"零决策级监督）；逐帧血差标签被血差轨迹主导（动作信号被淹没）；两者都不编码"金币×冷却 → 放不放得起闪电"。
- **但"金币×冷却条件"本身可能是我们的推测**，不一定是真实规律 ⇒ 网络学不出它，不一定是"病"，可能只是"我们猜错了结构"。

## 四、下一步（按"确定"优先）

1. **（确定）把 Q 网络的"闪电 >> 建塔/升级"先验接进统一搜索当类先验**：坏掉的那个类网（频率偏置、压低闪电）缺的正是这条；Q 网络能稳定提供它。
2. **（可选，测推测）冷却分层诊断**：建塔/升级偏导随冷却（cd=0 vs cd>0）怎么变，验证"花钱挤占放闪电"这个推测。
3. **（修值网主线）调研三条**：① 特征工程（moneyness/fireable）② UNREAL 辅助头（预测未来金币/能否放闪电）③ RUDDER/TVT 信用分配（把"放闪电→赢"的 credit 回溯给"攒钱"）。

## 五、一句话

**确定的是"闪电最值钱、统一搜索因经济失衡打不过 pin、而值网/Q 网络都读不出这个经济结构"；推测的是"这个结构具体长什么样（90 折点 / 金币×冷却条件）"。最可操作的下一步不是继续猜结构，而是把已确定的"闪电优先"先验先用上。**
