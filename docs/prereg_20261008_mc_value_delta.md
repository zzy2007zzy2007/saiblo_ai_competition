# 预注册：**让 MC 的评分"给花钱定价"**（`AZAI_MC_SCORE=delta` / `value_only`）

> 2026-10-08 第 8 轮写（**在跑之前**）。章程：`docs/task_ruleV4_90_charter.md`。
> 这是第 7 轮**剂量-反应线索**的**方法侧**版本（手写阈值只能当诊断 ⇒ 本预注册要的是**可交付**的形式）。

## 0. 由来（三条读数）

1. **正线索**：`AZAI_BUILD_MIN_COINS` = τ60 ⇒ `0.6875`（+3.1pp）、τ90 ⇒ `0.7031`（+4.7pp）；
   机制随阈值单调（建塔 **24.8 → 22.7 → 16.7**，τ90 时≈对手 16.6；闪电 10.5→11.1）。**两个阈值同号**。
2. **机理**：MC 的评分 = **安静 rollout 的终局血量差**，而**金币在"没人再出招"的世界里没有价值**
   ⇒ **花钱的好处立刻可见、代价不可见** ⇒ 机制**系统性过度花钱**（我们建塔 24.8 vs 对手 16.6）。
   这同时解释了"强制升级 **0/64**""仲裁加密 **−14.1pp**"为何大败（都是把"过度花钱"推得更远）。
3. **因此要动的是"评分函数"，不是加门槛**：

| 臂 | 评分 | 为什么是"无新超参" |
|---|---|---|
| **D（delta）** | `安静 rollout 分 + (V(after) − V(before))` | ① 第二项是 **potential-based shaping**（Φ=V）⇒ 理论上不改最优策略，只**修掉 rollout 的短视**；② 两项**同为 ±1 量纲**（HP 差已 ÷`HP_SCALE`）⇒ **1:1 相加**，没有自由权重 |
| **V（value_only）** | `V(after) − V(before)` | 纯用**学到的**价值网（其输入 `stats` **含金币**）⇒ 天然给资源定价；且**不用 rollout ⇒ 更快** |

- 价值网输入含 `stats` ⇒ 它**见过"钱少/钱多"的局面**（不像安静 rollout 里钱永远没用）。

## 1. 臂与配置（写死；除评分方式外一切不动）

| 臂 | `AZAI_MC_SCORE` | 说明 |
|---|---|---|
| 对照 | `''`（现状）| 安静 rollout 的终局血量差；同前缀 = **0.6562** |
| **D** | `delta` | rollout 分 + V 差分 |
| **V** | `value_only` | 只有 V 差分（无 rollout）|

- 公共配置 = `M6c-ROOT` 原样（`checkpoints/posnet_A_k5_m32.pt`、`ITERS=256 DEPTH=4 K=24 SAMPLE_MULT=15`、
  `POSPIN=mc_quiet MC_HORIZON=256 MC_EVERY=5 MC_ROOTONLY=1`；其余诊断开关全 0）。
- 每臂 **64 局 = 固定段前缀 `7..38`（32 对）**，`jobs=8`。**两臂都报**（不挑好看的）。

## 2. 判据（**先写死**）

- **晋级线**：`p̂ ≥ 0.6562 + 8pp = 0.7362` ⇒ 该臂进 **两段各 128 局验收** + 独立验证 + 记档。
- **机制读数（必报，且是本预注册的关键）**：
  **我方建塔数**（现状 24.8）、**闪电**（承重，10.5）、**出招回合**（32.2）、
  **对局回合**、`dec_max`/`dec_slow`（V 臂应当**更快**）、无效/超时。
- **机制前置判据（P1）**：**建塔数必须下降**（因为"给花钱定价"若生效，就会少花钱）。
  **若建塔没降 ⇒ 该臂的机制没激活 ⇒ 即使分数好看也不作结论**（第 2/3 轮踩过这个坑）。
- **成本闸门**：单局 >6 min ⇒ 只跑 64 局并记档说明。
- ⚠️ 64 局只分辨 >~12pp；单段不作结论；看数据前判据已写死。

## 3. 预测

- **P1（机制）**：**D 臂** ⇒ 建塔略降（V 项只在与 rollout 项可比时才起作用，量级约 0.01–0.06）；
  **V 臂** ⇒ 建塔**明显下降**（若价值网真的把金币当资源），`dec_max` **下降**（省掉 rollout）。
- **P2（分数）**：我估 **D 臂 +0～+4pp**（接近第 7 轮的剂量-反应，但幅度更小、因为无硬阈值）；
  **V 臂不确定**：可能更好（学到的东西比"没人出招"的世界更真），也可能更差（价值网的**分辨率**可能低于
  `HP_SCALE` 的 0.05 ⇒ 平局/噪声更多；2026-09 曾实测"塔位置只改 V 0.062、std 0.024"）。
- **P3（重要）**：若 **V 臂机制激活（建塔降）但分数不涨** ⇒ 说明"给花钱定价"这件事**只有靠外生阈值才有效**，
  即价值网在这条分布上学不出"金币的价值" ⇒ 那就要**改训练目标**（把金币/资源写进标签），而不是换评分。
