# 预注册：**把 K48 搜索的"格子偏好"蒸馏进位置头**（部署仍用 K=24）

> 2026-10-13 第 13 轮写（**在跑之前**）。章程：`docs/task_ruleV4_90_charter.md`。
> ⚠️ **换 ckpt = 机械门** ⇒ 若晋级须走独立验证 + 记档。

## 0. 由来（唯一"三段都非负"的配置变体 + AZ 式闭环的正当用法）

1. **K48（4× 搜索）的判据尺度读数**（第 11–13 轮）：
   固定段 `0.7419`（对照 `0.7344`，**+0.75pp**）、**随机段 `0.7578`（对照 `0.7031`，+5.5pp）**、
   合并 252 局 **+3.1pp（n.s.）**；三个块 **+11.1 / −9.4 / +5.5**（均值 +2.4、sd ~10.5）。
   ⇒ **作为"配置"不采纳**（分辨不出、代价 4×）。
2. **但它的方向是**：**"更深/更宽搜索排出来的格子"**——而**格子是当前配置里唯一被证明"承重"的决策**
   （K1 −56pp、K4 −25pp；位置级落点一致率 0.111/0.154）。
3. ⇒ **AZ 式闭环的正当用法**（不是"模仿自己"的固定点）：**把"更强的搜索"当教师，蒸进网络，
   部署时回到便宜的 K=24**。这正是 AlphaZero 的"搜索 ⇒ 策略"改进算子，只是我们把它用在**格子**这一维。
   ⚠️ **不是**在模仿 `rule_v4`/冠亚军（章程①），教师是**我们自己的更深搜索**。

## 1. 做法（三步，全部可复现）

### 1.0 ⚠️ 采集量修订（**在任何训练/评估读数之前**，理由 = 实测成本）
- 原写 **80 局**。实测：K48 自对弈每局 ~20–30 min（4× 搜索 + MC 的安静 rollout）
  ⇒ 80 局 ≈ **4 h+**。**修订为 30–40 局**（≈3 万决策，位置目标比类标签**密得多**：
  每个决策有整张 `(类, 格子)` 访问分布）。
- **保护措施（不改判据）**：① 蒸馏后**先过 P1（落点一致率 < 0.8）**，不过 ⇒ 判"学生没学到"并**直接关闭**（不补数据）；
  ② **训练读数必报**：位置目标上的拟合度（train/val 的位置 CE 或 argmax 命中率）；
  ③ 若 P1 过但效果不显，**不追加数据**（记档为"此配方/此预算下无增益"）。

1. **采集（教师）**：`az_selfplay`（部署配置 + `K=48/ITERS=512`）自对弈 **30–40 局**
   （种子 `70,010,000+`，**与判据 seed 不重叠**，章程③）⇒ `intent_counts` 里带**每个决策、每个头的候选格子访问分布**。
2. **蒸馏（学生）**：`az_train.py --policy-only --freeze-backbone`（策略损失 = 按 visit 边缘化到 per-head intent）
   ⇒ **只把 `pos_state` 嫁接回原 ckpt**（显式保证单变量）。**必须核**：只有 `pos_state` 不同。
3. **评估（判据尺度）**：部署仍用 **K=24/ITERS=256**（便宜），跑**固定段 128 局 + 随机段 128 局**。

## 2. 判据（**先写死**，吸取第 12/13 轮教训）

- **机制前置判据 P1（先过）**：**落点必须真的变** —— `cmp_op_cells.py` 报的**落点一致率 < 0.8**
  （否则说明学生没学到教师的东西 ⇒ **不作结论**）。
- **主判据（判据尺度，不用前缀筛）**：
  * **两段都非负** 且 **合并 ≥ +3pp** ⇒ **采纳**（走机械门：独立验证 + 记档）；
  * **一正一负** 或 合并 < +3pp ⇒ **不采纳**（记档；若合并为负 ⇒ 关闭该轴）；
- **成本闸门**：采集（80 局 @K48）≈ 1.5–2 h；训练 ≈ 10 min；评估（256 局 @K=24）≈ 2 h ⇒ 合计 ≈ 4 h。
- **有效性**：每批 无效+缺失 ≤ 10%，判词全 engine。

## 3. 预测

- **P1**：**必然通过**（教师的格子偏好与现状差异极大：K48 vs K24 的落点一致率已测 = 0.154）。
- **P2（主判据）**：我给 **"合并 ≥ +3pp"约 30–35%**。理由：
  ① K48 的三块读数里 **两块为正**、合并 +3.1pp（虽然 n.s.）；
  ② 若那 +3pp 是"搜索质量"带来的，蒸馏**有可能**把它搬到 K=24 上（且成本降 4×）；
  ③ 反方：K48 的效应本身没被分辨出来（±6pp），蒸馏只能搬"教师做对的那些格子"，
  而**教师与学生的差异也可能主要是噪声**（第 10 轮的教训：表示层的"学会"不等于决策改变）。
- **P3**：若 **P1 通过（落点大变）但两段都变差** ⇒ 说明"K48 的格子偏好"在 K=24 的搜索框架里**不适用**
  （教师-学生不匹配）⇒ 该方向关闭，并记入"蒸馏在决策层无效"的第二例。
