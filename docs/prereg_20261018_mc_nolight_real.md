# 预注册：**把 Phase 0 的发现搬到真实对局**（`AZAI_MC_NO_LIGHT=1` + 放宽经济菜单）——判据尺度判决

> 2026-10-18 写（**在跑之前**）。章程：`docs/task_ruleV4_90_charter.md`。
> 来源：Phase 0（`docs/prereg_20261017_phase0_nolightning.md` 与其附录）——**在禁闪电的子博弈里**，
> `MC_UPG=1 + MC_TOPK=3` 让**经济动作第一次被中等强度地用起来**（建 20.2 / 降 8.7 / **升 2.8** 每局，且不 churn），
> 对官方 example 的胜率从 **0.0156 → 0.4375**。⇒ 本预注册把**机理**（闪电在 MC 菜单里挤掉经济/升级候选）搬到**真实对局**。

## 1. 假设与干预

**H17**：真实对局里，MC 菜单中的**闪电候选**几乎总是赢过经济/升级候选 ⇒ 经济动作（尤其**升级**）被挤掉。
把**闪电移出 MC 菜单**（`AZAI_MC_NO_LIGHT=1`；闪电仍由**非仲裁回合的默认规则**"买得起就放"负责），
同时**放宽经济菜单**（`MC_UPG=1`、`MC_TOPK=3`）⇒ 经济/升级候选获得公平比较 ⇒ 行为改变、棋力提升。

| 臂 | 配置 | 说明 |
|---|---|---|
| **对照** | `M6c-ROOT` 原样 | 固定段 `0.7344` / 随机段 `0.7031`（都已零漂移复现）|
| **NL-R** | `+ AZAI_MC_NO_LIGHT=1 AZAI_MC_UPG=1 AZAI_MC_TOPK=3` | 本臂。**除这三个开关外一切不动**（不换 ckpt ⇒ 非机械门）|

## 2. 判据（**先写死**；按第 9 轮铁律用**判据尺度**，不用前缀筛）

1. **机制前置判据（先过，且必须报）**：
   * **升级 > 0**（现状：真实对局 0.0/局）；
   * **闪电不塌**：我方闪电/局 ≥ 8.0（现状 10.5；`L180` 证明闪电是承重的，**若掉到 <8 ⇒ 直接判失败**）；
   * **不 churn**：降级 ≤ 建塔/2（现状 10.9 vs 24.8 —— 本来就接近，放宽后若降级 > 建塔/2 ⇒ 判失败）。
   * **机制不过 ⇒ 不作棋力结论**。
2. **主判据（判据尺度）**：跑**固定段 128 局 + 随机段 128 局**（合计 256 局，K=24 下 ≈1.5–2 h）：
   * **两段都非负** 且 **合并 ≥ +3pp** ⇒ **候选** ⇒ 走机械门（独立验证 + 记档）；
   * **合并 ≥ +8pp 且无一为负** ⇒ 更强（可考虑正式验收流程）；
   * 一正一负，或合并 < +3pp ⇒ **不采纳**（记档）；
   * 合并 ≤ −3pp ⇒ **关闭该轴**。
3. **有效性**：无效+缺失 ≤ 10%，判词全 engine。

## 3. 预测

- **机制**：升级 **必然 > 0**（Phase 0 里 E2 已 2.8/局）；闪电会掉一些（MC 回合不再选闪电 ⇒ 约 −20% 的回合里少一次机会）
  ⇒ 我估闪电 **8.5–10.0/局**（压在闸门边缘）；降级我估 ≤ 建塔/2。
- **棋力**：**不确定**，我给 **合并 ≥ +3pp ≈ 30%**。理由：
  ① 正：这是 17 轮里**第一次**看到"经济动作被中等强度用起来"的配置，且**升级从 0 变成非 0**（对手一直 9.5 次/局，我们 0 —— 这是最明显的"缺一门"）；
  ② 反：Phase 0 的 +42pp 是**在闪电被完全禁掉的子博弈里**测的，搬到真实对局时"闪电-经济"的**时机耦合**完全不同（历史上手写储备规则在旧配置 +13pp、新配置 −45pp 就是这种不迁移的例子）。
- ⚠️ 若机制过、棋力**显著变差** ⇒ 说明"闪电被挤掉"这一维**在真实对局里是有益的约束**（即菜单里的闪电候选在保护我们）⇒ 记录并关闭。
