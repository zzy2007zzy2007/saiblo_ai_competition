> 2026-10-07 00:3x 写（**在跑之前**）。章程：`docs/task_ruleV4_90_charter.md`（判据 = 两段各 128 局都要 ≥90%）。

## 0. 为什么做这个（三条事实）

1. **监督覆盖本来就偏**：本任务线的自对弈/采集里**位置监督 100% 来自闪电行**
   （`memory/project_az_posnet_v2_two_stage.md`：24,972 决策点、100% 类 17；每通道样本 8,324 vs ~761）
   ⇒ 非闪电通道**从来没被好好监督过**；而**现在**我们的机制**真的在花经济**（建塔 25–28 座/局，A1 是 **0**）
   ⇒ **"塔放哪儿"第一次真正影响胜负**。
2. **我们有现成的、干净的单变量材料**：`checkpoints/posnet_A_k5_m32.pt`（在用）/ `posnet_A1_km1_m32.pt` /
   `posnet_B_km1.pt` **三者的 `class_state`、`value_state` 逐张量相同、只差 `pos_state`**
   （2026-10-06 用子网哈希核过；见 `docs/checkpoints.md` §1 末尾）。按同一份 memory，**A1 的非闪电通道是随机初始化**的对照臂
   ⇒ 本对照等于"**多类记录训出的位置先验 vs 近似无先验**"。
3. **那条线的判据当年没跑完**：memory 写"三臂采集/训练完成，**判据待跑**"（2026-09-20）；
   且当时的两个判据方向相反（闪电判据 +9.0pp / 塔判据 −6.25pp，均不显著）⇒ **未证实**。
   **换 ckpt = 机械门**（章程 §4）⇒ 本预注册 + 任何胜者都要独立验证。

## 2. 判据（**先写死**）

- **筛选读数**：每臂 `p̂`（配对分，同 R0 口径）。
- **晋级线**：`p̂ ≥ P-A 同前缀读数（0.6562） + 8pp = 0.7362` ⇒ 该臂进**两段各 128 局验收**；
  否则记"**位置网换臂在 64 局下无差异**"（**不作结论、只说没看到效应**）。
- **必报的机制读数**（用来解释，不用于判定）：建塔/升塔/闪电/出招回合、**决策耗时**（`dec_max`/`dec_slow`）、
  以及"塔的落点分布"是否变化（若三臂行为几乎一致 ⇒ 说明位置先验在机制里**几乎没被用到**）。
- **成本闸门**：单臂 64 局 > 90 min ⇒ 只跑该臂并记档说明。
- ⚠️ **单段读数不作结论**；⚠️ **不许在看过数据后改判据/改 seed**。

## 3. 预测（写下来，事后对照）

- **P1**：**P-A1（近似无先验）与 P-A 的分数差 ≤ ±3pp** ⇒ 说明"位置先验的质量"**不是当前瓶颈**
  （与 2026-10-06 的格子级诊断一致：经济类上先验 top-1 只落在结果代理的 **39%** 百分位）。
- **P2**：三臂的**建塔/出招统计**会有可见差异（先验影响落点 ⇒ 影响塔的生存/输出），但**分数不变**。
- **P3**：若 P-B 明显更好（≥ +8pp）⇒ 位置网这条轴**有真余量**，值得按 memory 的"第 2 段"继续做。
