## 二、六条线的核心结论

### A. 大动作空间的搜索（`a_large_action_search.md`）

| 结论 | 等级 |
|---|---|
| 我们把预算**均匀摊给所有候选、每个只采一次、直接 argmax** ⇒ 这是文献里"噪声主导选择"的最坏情形 | [正文] Karnin 2013 + [推理] 用我们自己的 σ/Δ 算出 |
| **266 候选取 max 的噪声偏差 ≈ σ·√(2ln k) = 3.34σ ≈ 371，是真实分差 71 的 5 倍**；n=15 时仍有 ≈96 | [推理]（基于项目 σ、Δ） |
| 同样 3.9 万回合预算下，**Sequential Halving** 可把冠军的样本数从 15 提到 ≈338（SE 从 ≈29 降到 ≈6）| [正文] Karnin COLT 2013 算法与界 |
| SH 的前提是**候选去重**：近重复候选使 Δ≈0、`H₂=Σ1/Δ²` 爆炸 ⇒ 最坏界失效；目标应改为"别选明显差的" | [正文] 同上 + [推理] |
| Gumbel 的正确用法是"**同一组 Gumbel 噪声同时决定候选集与选中者**"，按 logits 取 top-k 再独立加噪会丢掉无偏性保证 | [正文] ICLR 2022 slides + 讲义公式 |
| Sampled MuZero 只有"依分布收敛 + O(1/√K) 正态近似"，**没有有限样本/带噪 q̂ 的界** | [正文] |

### B. 结构化/可组合动作（`b_structured_actions.md`）

| 结论 | 等级 |
|---|---|
| 该抄的是 **factorized/autoregressive action head**，不是 HRL（options/FeUdal 解决跨时间技能复用，我们的因子在同一决策内）| [二手]（options 原文被墙，正文未读）|
| 因子化必须**顺序化 + 每步重算 mask**；并行分支独立贪心会产出"每维合法、合起来非法"的束，而我们非法即判负 | [正文] Maskable PPO / shielding |
| 硬约束优先 **masking/shielding**，不推荐 CPO/Lagrangian | [正文] |
| "表达不了协同"的确切位置是**提案可达性**（现有 map+3 头 ≈ 各因子边缘乘积），而非策略网无法表达 | [推理] + [正文] |
| 多因子同时搜：成本≈相乘、收益≈相加 ⇒ 只把有空间的因子搜到饱 | [推理] |

### C. 稀疏/延迟奖励（`c_reward_shaping.md`）

| 结论 | 等级 |
|---|---|
| potential-based shaping `F=γΦ(s')−Φ(s)` + Φ 只用状态 + **Φ(终局)=0** 才不可被刷分；第三条在 Theorem 1 里 | [正文] Ng 1999（逐页读图）|
| **"安全"与"无用"是一体两面**：满足条件时对任何策略都最优（Remark 2 原文）⇒ **不能用 shaping 教新东西** | [正文] |
| 我们的"攒金币不做事"就是 Ng 1999 引言的原始环路 bug；若 `Φ_gold(终局)≠0`，整局求和 = `ρ(gold_T−gold_0)` ⇒ ρ>0 必攒钱，**是形状问题不是调参** | [正文] + [推理] |
| `Φ=V` 在 actor-critic 里**精确抵消优势函数**（A'=A）⇒ 当训练奖励无效；唯一有效位置是**搜索的评估函数** | [正文] 代数推导 |
| 血量差当 potential **只在 γ=1 时**满足 invariance；γ<1 会退化成"贴现的短期掉血" | [正文] + [推理] |
| MuZero 的 value target 混合的是"真实 n 步奖励 + **搜索值 ν**"，且**棋类直接到终局 z、不混合**（n=10 只给 Atari）| [正文] MuZero 原文 |

### E. 评估协议（`e_evaluation_and_recipes.md`）

| 结论 | 等级 |
|---|---|
| **SPRT 有闭式解**：α=β=0.05 时 `E[N]=5.30σ²/Δ²`（H1）/ `8.67σ²/Δ²`（最坏）；固定样本是 `10.8σ²/Δ²` ⇒ SPRT 省一半 | [正文] fishtest 统计文档 |
| 代入我们：判 **5pp 需最坏 3468 局 ≈ 12.6 小时**，判 10pp 需 867 局 ≈ 3.2 小时 ⇒ "4 小时判 5pp"不成立，必须分层预算 | [正文]+[推理] |
| 配对省方差有恒等式 `V₃−V₅=E(b²)`（实测省 17%），但**配对消不掉座位主效应**（那是 design 问题，要用协变量）| [正文] |
| 47pp 座位差 = 355 Elo **大得反常**，应优先排查对称性/位置编码，而不是接受 | [正文] Ordo/BayesElo 量级 + [推理] |
| **winner's curse**：测 20 个 checkpoint 挑最好 = 挑噪声 ⇒ 可解释我们"离线 +4.7pp / 实战 −20pp" | [正文] LZ #676 |
| LCZero 官方 FAQ：自对弈 Elo "is not a true indicator of net strength" ⇒ 离线指标应降级为冒烟测试，并拟合"离线→实战 Elo"校准曲线（R²<0.5 就禁止做门禁）| [正文] |

### F. 低算力可行性（`f_low_compute.md`）

| 结论 | 等级 |
|---|---|
| 追平 KataGo 主 run 需 **≈146 个月**、AlphaGo Zero **≈170 个月**、最省算力的象棋自对弈（325 万局/480 GPU·h）**≈113 个月** | [正文] + [推理] 换算 |
| 但我们的月决策量是 Atari-100k 的 **≈39 倍** ⇒"**少样本、强监督**"这条路我们占优 | [正文] + [推理] |
| 数据:训练 算力比 ≈1100:1（KataGo 24:1）⇒ **投训练收益天花板极低，投采集吞吐收益极高** | [正文] + [推理] |
| **不该上完整 MCTS/AZ**：不是算不动（800 次模拟 ≈1.28 万转移仍在预算内），而是**值网语义错位**（我们值网 = "16 步 rollout 后的期望"，给浅层 leaf 打分是错的）+ 266 路分支每候选只够 3 次访问 | [正文]+[推理] |
| 可行清单：无树候选筛选 + 自适应预算、playout-cap 记录（只记 25% 全搜索回合）、训练侧全套餐、少量离线 Reanalyze、**少模拟 Gumbel（MiniZero 实测 2 与 16 次模拟可用）**、搜索→先验蒸馏 | [正文] |

### D. 先手承诺序列博弈（`d_sequential_commitment.md`）

| 结论 | 等级 |
|---|---|
| 局面全可见 ⇒ 信息集是单点 ⇒ 这是**完全信息扩展式博弈**，解概念是 **SPE（逆向归纳）**，不是 Stackelberg 均衡；P0 的均衡首着 = `argmax_{a0} min_{a1} V` | [正文] Conitzer & Sandholm EC'06 |
| **P0 用混合策略在理论上弱劣势**：P1 看到的是**实现值**而非分布 ⇒ `E[min] ≤ max min`；混合只能当 exploit，**应从主方案降级** | [正文] + [推理] |
| 座位差量级格格不入：棋类锚点 3–5.5pp、项目内 AntWar 后手优势 5.4%；**项目史上同型的 28.1pp 在配对补测里归零**（53.1% vs 53.1%）⇒ 更像"搜索只在 P1 侧有增益 + 小样本伪影"，**先配对 + McNemar 重测** | [正文] |
| 落地（10 s 内可行）：只改 P0 侧打分——先验截到 K0=8，每个 a0 取对手 top-3 回应（用我们自己的网当对手模型），softmin_β，预算 **0.64 s/决策**；完整 2-ply + rollout 需 184 s，**不可行** | [推理] 预算推算 |
| **瓶颈不是时间而是候选数**：91.6% 的决策只有 1 个候选、80% 被 SKIP1 短路 | 项目实测 |
| 零成本诊断："回应值缺口"——`argmax` 一致率 <70% ⇒ 方案值得做；>90% ⇒ 查价值网座位校准 | [推理] |

## 三、跨线收敛的五条结论

1. **不该走完整 AlphaZero/MCTS**（算力差 100 倍 + 值网语义错位）——**F 线，[正文]+[推理]**。
2. **该做 Sequential Halving**：同预算精度 +5 倍；我们现在的选择已处在"靠噪声"区间——**A 线，[正文]+[推理]**。
3. **不该做奖励 shaping**（安全与无用一体两面；金币是形状问题）——**C 线，[正文]**。
4. **该把"血量/值网"放进搜索的评估函数**（Φ=V），而不是训练奖励——**C 线，[正文]**。
5. **评估协议必须换**（SPRT + 配对 + 座位协变量 + 警惕 winner's curse），否则一切 A/B 不可信——**E 线，[正文]**。

另外两条工程性好处（**收益确定、不需算法变更**）：

6. **算力应投在采集吞吐**（数据:训练 = 1100:1，KataGo 是 24:1）。
7. **动作头长期应走向 factorized/autoregressive**（+ 每节点重算 mask）——**B 线，[二手]/[正文]**。

## 四、路线图（按性价比排序，含判据）

| 优先级 | 事项 | 依据 | 成本 | 判据（先写死） |
|---|---|---|---|---|
| **P0** | **Sequential Halving** 替换均匀分配（先做离线验证，再上对局）| A | 1 h 改码 + 30 min 离线 | 零对局指标：top-1 命中率 / simple regret 相对 n=128 参考提升 ≥30% |
| **P0** | **评估协议换成 SPRT + 协变量** | E | 1 h | 能给出"判定 5pp 需多少局/多少小时"的预估，且与实测一致 |
| **P1** | **座位差排查**：旋转增强（rot180 + 我方/敌方通道交换）+ 双座位等量采样 | E + [推理] | 1 h 读通道表 + 1 h 实现 + 1 次重训 | 两座位 action_map 相关性从 0.23 明显上升；座位差从 27pp 缩小 |
| **P1** | **搜索评估用 Φ=V（delta 臂）** | C | 需改搜索 | 对局血量差改善，且不出现"苟血"（终局金币作为专属性指纹）|
| **P2** | 采集吞吐提升（并行 rollout、批量值网、前缀共享、playout-cap 记录）| F | 数小时 | 同样墙钟内采集局数 ×3-8 |
| **P2** | 动作头 factorized/autoregressive（条件化续加 + STOP + 每步 mask）| B | 数天 | 束级召回上升；否则价值网几乎不选配对候选 |
| **P3** | 换教师（多采样随机化 rollout 的均值当标签）| 项目历史 + A/F | 采集 ×K | 离线 recall 与实际对局同时改善（当前二者脱钩）|

## 五、诚实边界（务必一起读）

- **[正文] 覆盖率**：A/C/E/F 的核心文献读到了正文或官方文档；**B 线的 AlphaStar/options 原文被付费墙挡住，仅二手**；**D 线待补**。
- **[推理] 部分**：第二节里所有"代入我们数字"的换算（如 371 vs 71、146 个月、SPRT 局数）都是我们用自己数据算的，**不是文献结论**。
- **明确找不到的**：`"Revisiting AlphaZero"` / `"How much compute does AlphaZero need"` 均无同名文献；SAI 未找到；"塔防 + 组合动作 + 硬约束 + 稀疏奖励"的交叉方法**未见**（可能是这个题目的空白点）。
- **样本/统计的坑**：winner's curse（多 checkpoint 选优）、座位差（47pp）会掩盖一切 <10pp 的效果；**任何 <10pp 的改进在当前协议下都不可判**。

## 六、下一步（我建议的执行顺序）

1. **先做零对局的离线指标**（SH vs 均匀分配），因为它是唯一不消耗对局预算就能验证的东西；
2. 再把评估协议换成 SPRT（否则后面所有实验白做）；
3. 然后做座位差排查（旋转增强）——它直接指向最严重的 27pp；
4. 最后才是"换教师/换动作头"这类需要重训的大改。

> 一句话：**先把"能不能可信地测量"和"预算怎么分配"解决，再谈模型和算法。**

## 七、补充线：AlphaZero 家族与 PPO 家族（2026-10-26 追加）

### G. AlphaZero 家族变体（`g_alphazero_variants.md`，14 篇读正文）

| 结论 | 等级 |
|---|---|
| **唯一同时解决"分支多 + 采样带噪 + 预算极薄"的是 Gumbel 系**；唯一解决"数据贵要榨干"的是 KataGo 系；其余（learned model / 连续动作 / 随机环境 / 大规模分布式）对我们负收益，文档列了 14 条"不必看" | [正文] |
| ① **同一组 Gumbel 决定候选集与选中者 + `σ(q)` 缩放**：可消掉 `σ√(2ln k)≈371` 的选择偏差。⚠️ 我们的 q 是"血量差"量纲（几百点），**必须先无量纲化**（建议 /200），否则 σ 会放大噪声 | [正文]+[推理] |
| ② **`π_MPO = softmax(logπ_θ + σ(q̂))` 当策略目标**：我们已有 q̂，零额外计算，且绕开"没有访问计数"的结构问题；风险是 q̂ 噪声大时退化成 one-hot（看目标熵诊断）| [正文] |
| ③ **分层预算**（KataGo playout cap 同构）：91.6% 单候选决策可做 0 次 rollout，省下的灌给 8.4% 关键决策 ⇒ SE 从 29 降到 ~9 | [正文] |
| ④ 值头改 **HL-Gauss** + 结构化辅助头（血量差/塔数/金币）：KataGo 辅助头消融 1.65×。⚠️ **Stop Regressing 实测 Two-Hot 在线 RL 反不如 MSE**，别抄 MuZero 的 two-hot | [正文] |
| ⑤ **离线 Reanalyse**：用当前网重标存量决策（我们数据:算力 1100:1）。优先级用 `\|q̂−z\|` 时噪声可能占比过高，建议改 Brier 或多次均值 | [正文] |
| 一行改动但几乎一定对：**Dirichlet 改总 α 恒定**（`α = 10.83/n_legal`）—— 我们合法候选数在 1~266 剧烈波动，固定 α 在只有 1 个候选时等于注入 100% 噪声 | [正文] KataGo |
| **依赖关系**：① 的效果强依赖"先把 k 缩到 8-16"（log₂266≈8 阶段，每阶段只剩 2 次采样）⇒ **缩小候选集是 Gumbel 方案的前提，不是可选项** | [正文]+[推理] |

**纠正**：`ReZero` 这个方向不存在（arXiv 同名是 LLM 检索方向）；`2103.04931` 是 MCTS 综述（Sampled MuZero 是 `2104.06303`）；Gumbel MuZero 无 arXiv 版（OpenReview 403，公式取 MiniZero + MA-Gumbel 正文复述）。
