# 实体 Transformer 价值网 + 亚军价值消融 —— 结果汇总

> 2026-10。对应 `docs/plan_entity_transformer_value.md` 的三步，本文记录第 1 步（value）与
> 亚军价值消融的结论。**重要：修正了之前"价值近似线性、网络表达不了"的错误结论。**

## 1. 数据

| 数据 | 来源 | 样本 |
|---|---|---|
| 128 局亚军自对弈 | 桥接 `MVS_RAW_STATE_DIR`（board+stats+实体+value）| 127,578 |
| 2 局 rollout dump | 亚军 `-DLURE_DUMP_VALUE`（单边实体+value）| 184,368（~9 万/局）|

## 2. 价值拟合（同一划分：train 96 局 / val 32 局）

| 模型 | val R² | val MAE |
|---|---|---|
| **实体 Transformer（塔/蚁 token + stats，46 万参数）** | **0.9969** | **65** |
| 实体 Transformer + 格 token（完整版）| 0.9958 | 75 |
| 线性（42 stats）| 0.9459 | 348 |
| CNN（board+stats，8 局小样本时）| 0.922 | 619 |

**结论**：
- **架构能表达亚军价值**（R² 0.9969，MAE 65），**之前"网络打不过线性"是数据饥饿**
  （8 局 6k 样本 → 0.902；128 局 95k 样本 → 0.9969）。
- **格 token 无增益**（实体 + stats 已覆盖），精简版即可。
- **rollout dump 不能替代对局采集**：单边、缺 42 维 stats ⇒ 跨局 val R² 只有 0.624。

## 3. 亚军价值消融（重建亚军 + 32 局对战，seed 700–731）

本机重建亚军见 `docs/runnerup_build_note.md`（关键：Windows 需 `_setmode(_O_BINARY)`）。

| 变体 | 变体胜率 | 结论 |
|---|---|---|
| **zero**（价值=0，纯 heuristic）| 5/32 = 15.6%（−3.9σ）| **价值是命脉，去掉就崩** |
| **linear**（base_hp*200 + 等价金币*10）| 13/32 = 40.6%（−1.07σ，p≈0.28）| 可能略差，但 32 局不足以定论 |

离线消融（seed900 plans 日志）：去掉价值项后 **41.8%** 的决策 argmax 改变。

## 4. 待办

- linear 消融补到 64–128 局（32 局置信区间 [24%,59%] 太宽）；
- 若要把网络塞进亚军：受限于 `rs::DefenseSimulator` 是**单边**（只有己方塔+敌方蚁），
  只能用单边输入的小模型；完整状态模型（0.997）塞不进去，除非大改 rollout。
