## 最终判定

1. **"先验 + 降 k + 大采样"这条主线在内部成立**（+5.08hp，两次复现，CI 不含 0），
   **但对外 0 胜 16 负、血量差与冠军基线无差异（还差 1.6hp）**；
2. 结合今晚其他读数（值网仲裁 +19pp、广度 +15.6pp、随机化 +3hp 也都未传导），
   **结论：内部自对弈 A/B 不能作为"变强"的证据**；今后任何改进都必须过
   **对外关卡（16 局 vs 亚军，看血量差 vs −26.3）**；
3. 今晚唯一真正有效的改进是**引擎级修复**（升级动作从未执行、rollout 确定性导致 16× 算力浪费），
   而不是任何"策略偏好"上的调整。

## 明天的建议

- 若要继续提升**绝对强度**：目标函数必须直接用对外指标（vs 亚军），
  而不是"内部胜率/血量差"。可选路径：
  1. 针对亚军行为做针对性训练（需要它的行为分布数据，我们已有 128 局自对弈的 value 数据 + 101 局对战回放）；
  2. 继续走"引擎级修复"路线：找还有哪些动作从未被执行、哪些搜索路径被静默跳过
     （今晚证明**这类修复是唯一能传导到外部的**）。
- 若只是想理解先验机制：本次已得出结论（f10 平坦 ⇒ 候选多样 ⇒ 内部变强），但它没有实战价值。
