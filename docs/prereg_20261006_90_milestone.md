# 预注册：第二里程碑（vs `rule_v4` 配对胜率 ≥ 90%，固定段 + 随机段）

> 2026-10-06。章程：`docs/task_ruleV4_90_charter.md`（由 `_70_` 版复制升级）。
> 本预注册**在跑任何 90% 相关的验收之前**写定；**判据、两段 seed 集合、样本量都不许事后改**
> （看见数据后再加样本，只有按预先写好的延长规则加才算数，否则那批读数作废）。

## 1. 判据（唯一验收）

`vs rule_v4`、**两段各 128 局 = 64 对镜像**，**两段的配对胜率都要 ≥ 90%**：

| 段 | seed | 局数 | 目的 |
|---|---|---|---|
| **固定段** | `7..70`（沿用第一里程碑）| 128 | **比历史**（可直接对照 0.7344）|
| **随机段** | 见 §2（64 个，预先抽定并记录）| 128 | **防挑臂**（没被挑过的尺子）|

- 配对 = 同一 seed 的 `N`（我方先手）/ `Nr`（对手先手）两局；对得分 = 我方胜局数 ÷ 2；段胜率 = 各对得分的平均。
- **两段都过线**才算达标；只有一段过线 = **未达标**（如实记录，不得只报过线那段）。
- 有效性门槛：**无效 + 缺失 ≤ 10%**；判词必须来自引擎（引擎/协议钉死见章程 §2）。
- 动机：第一里程碑的教训 = 判据段 `0.7344` 过线、**样本外只有 `0.6875`** ⇒ 单段读数可能被
  "在 `7..70` 上挑臂"污染。

## 3. 成本（据章程 §1 成本规则）

- 一次验收 = **两段各 128 局 = 256 局 ≈ 11 h**（一局 ~20 min、8 路并行）。
- 快读数**只取固定段前缀**，且样本量必须写进**当次预注册**（防 optional stopping）。

## 4. 起点与基线（测什么）

- **待测起点（当前最好）**：`M6c-ROOT`（`POSPIN=mc_quiet MC_ROOTONLY=1 MC_HORIZON=256 MC_EVERY=5` + A1 其余）。
  固定段已知 `0.7344`；**随机段未知** ⇒ 先各跑一遍，得到"距离 90% 还差多少"的两段读数。
- **可选**：`A1` 基线固定段已知 `0.5312`；若要在随机段也报告"变强了多少"（章程 §1 要求），需补跑随机段的 A1。
- 报告必写：**变强了多少**（即使没过 90%）。

## 5. 训练/评测分离（硬约束）

- **两段 seed（`7..70` + 上面这 64 个）跑出来的任何对局数据，都不得作为训练样本**（章程 §2 第③条）。
- 训练数据必须用与判据 seed **不重叠**的 seed 采集，并记档披露 + 报自对弈旁证。

## 6. 与第一里程碑的关系

- 第一里程碑（≥70%）**已达成**（钉死协议 `p̂ = 0.7344`，2026-10-06）；章程 `docs/task_ruleV4_70_charter.md` 转历史。
