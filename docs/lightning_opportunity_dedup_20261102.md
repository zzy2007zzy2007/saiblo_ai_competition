# 闪电机会去重统计（2026-11-02）

## 结论一句话

去重后「实际放闪电的比例」从原始的 **43.6%** 升到 n=5/10/20 的 **63.1% / 68.9% / 76.6%**，说明 3,811 个「可放闪电回合」里约 **31%（n=5）到 43%（n=20）** 是「同一波机会里反复出现」的回合——大部分来自「钱够、闪电冷却已好、却连续/邻近多回合没放」的情况，被合并进同一个机会后分母缩小、命中率自然抬高。

## 口径

- **可放闪电回合** = `coins[player] >= 90` 且 `weapon_cd[player][1] == 0`（闪电冷却，cost=90 / cooldown=35）。
- **放了闪电** = 该决策的 `chosen` 束里含 op 21（`USE_LIGHTNING_STORM`）。
- player 0 与 1 都算；每个 `(game, player)` 独立去重。
- 数据：`training_history/collect_v2_s1/*.cand.jsonl` + `*.ents.jsonl`（1:1 对齐，256 局、172,752 决策）。
- 参考口径 1,660 / 3,811 ≈ 43.6% 已复现（实测 1,660 / 3,811 = 43.558%）。

## 去重定义（单链接聚类）

对每个 `(game, player)`，把可放闪电回合按 `round` 升序排列；相邻两回合的
**间隔 = 回合号之差 `gap = round[i] - round[i-1]`**，`gap <= n` 就合并（传递合并）。
`n = ∞` 即不合并 = 原始口径。

## 结果

| n（间隔阈值，回合） | 机会数（新分母） | 放闪电机会数（新分子） | 比例 |
| ---: | ---: | ---: | ---: |
| 5 | 2,631 | 1,660 | **63.09%** |
| 10 | 2,411 | 1,660 | **68.85%** |
| 20 | 2,167 | 1,660 | **76.60%** |
| ∞（不合并） | 3,811 | 1,660 | 43.56% |

## 为什么分子恒为 1,660

闪电冷却 = 35 回合 > 所有 n（5/10/20），所以两次放电之间至少隔 35 回合，绝不落入同一个
去重簇 ⇒ 每个「放了闪电」的回合各自独立成一个机会。因此「放闪电机会数」恒等于放电回合数
1,660，去重只压缩分母（3,811 → 2,631 / 2,411 / 2,167），命中率从 43.6% 一路升到 76.6%。

## 可放闪电回合的结构（辅助证据）

相邻可放闪电回合的间隔分布里，`gap=1`（连续可放）占 23.8%，`gap=2~20` 合计再占约 21%，
`gap=35~44`（放电后冷却转好、下一波机会）占约 21%。连续可放段（gap==1）里 2,733 段只有
1 个回合、另有 170 段长 2、42 段长 3……正是「一波机会拖成多回合」的来源。
