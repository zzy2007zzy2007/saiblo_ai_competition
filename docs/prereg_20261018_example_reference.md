## 1. 假设与臂

⇒ **闪电正常时**我们应当明显强于它（H1：`p̂ ≥ 0.85`）；若**并非如此**（H2：`p̂ ≤ 0.70`，即连"正常制度"都打不过它），
那就是一条比 Phase 0 更严重的发现，需要单独立项。

## 3. 判读（**先写死**）

- `p̂ ≥ 0.85` ⇒ **H1 成立**：example 在真实对局里确实弱（与用户直觉一致），
  Phase 0 里我们对它 0.0156 完全是"**被禁闪电后我们不会玩**"的症状，而不是"它很强"。
- `0.70 < p̂ < 0.85` ⇒ 它在真实对局里有相当水平（不是弱对手），Phase 0 的读数需要双重解释。

  有相当成分是"对 rule_v4 这一特定规则的适配"，泛化性比我们以为的更窄（**这条要单独立项**）。
