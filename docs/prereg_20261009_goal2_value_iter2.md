# 预注册（本 goal 第 43–50 轮）：**价值迭代第二轮**（用改进后的网重新采"搜索值"）

> 真实日期 **2026-10-09**。章程：`docs/task_ruleV4_90_charter.md`。上位目标 `goal-2600a56a`（对冻结基线两段各 ≥80%）。
> 关联：`prereg_20261019_goal2_s2_value.md`（价值重训）、`docs/goal2_vs_baseline_report.md` §4b（机制天花板）。

## 0. 为什么这是唯一能"抬高天花板"的路径

- 已实测：`value_state` **每次决策都进入搜索叶评估**（`make_three_net_fn(class,pos,**value**)`；同局面换网 ⇒ 叶值 −0.168 → +0.439）；
- 已实测：**"从搜索蒸馏价值"的目标好学得多**（按局 `val_mae 0.0718` vs 终局目标 `0.3453`，低 4.8 倍）；
- 其它杠杆**逐一被否**：仲裁覆盖已用到 100%（MC1 = 0.6797）、类菜单加宽**不可迁移**、格子菜单**有害**、迭代数**有害**、安静 rollout 视野**无变化**、把价值网当 MC 评分器**远不如 rollout**（0.4531 vs 0.9375）。
- ⇒ 若"更好的叶值 ⇒ 更强的搜索 ⇒ 更高的判据"这条链成立，就可以**逐轮迭代**（每轮：用当前网采搜索值 → 训网 → 装回去 → 评）。

## 1. 进入条件（**先看第一轮判据读数** `AB_VSEARCH_dec_vs_baseline`，对照 MC1 = **0.6797**）

| 第一轮判据 `p̂` | 判读 | 本文件是否执行 |
|---|---|---|
| **≥ 0.72**（≥ +4pp）| 价值通道**确实提升搜索** | ✅ 执行第二轮（并可考虑第三轮）|
| 0.68 – 0.72 | 信号微弱（在 ±4pp 噪声带内）| ⚠️ 仅在机时充裕时做**一轮**；结论一律写"不显著" |
| **< 0.68** | 更好的叶值**没有**转化为棋力 | ❌ **不执行**；价值线关闭，如实记录"该管线里价值通道已到顶" |

## 2. 协议（每轮固定）

1. **采集**：用**当前最好的 ckpt**（第一轮 = `checkpoints/grafted_sdk_A_vsearch.pt`）+ **MC1 配置**双方禁闪电自对弈 **60 局**，
   继续用**训练专用 seed 段**（`≥10000`；**判据段 7..70 / 随机段 / 未见段 501..564 一律不入训**——章程③）；
   同时开双 dump：观测（`AZAI_DUMP_RAW_DIR`）+ **搜索软策略/根值**（`AZAI_AZ_DUMP`）。
2. **转换**：`azjsonl_to_value_npz.py`（目标 = `root_value`）→ `data/s2v_npz_r2`。
3. **训练**：`train_value_antwar.py --data-dirs data/s2v_npz_r2 --base checkpoints/grafted_sdk_A.pt --out checkpoints/grafted_sdk_A_vsearch2.pt`
   （同架构 + `MSE(tanh(v), target)` + **按局切分** + **只替换 `value_state`**）。
4. **评估**：**判据臂**（`MC1` 配置 + 新 ckpt vs **冻结基线**、全固定段 128 局）⇒ 与 **MC1（0.6797）** 和 **第一轮** 比。
   任一 ≥0.80（两段）⇒ 走机械门 + 独立验证。

## 3. 护栏（先写死）

- **发散护栏**：若第二轮的按局 `val_mae` **劣于**第一轮（0.0718），判"自举发散"⇒ 中止并记录（AZ 价值自举的已知失效模式）。
- **不可比的护栏**：每轮的采集/评估配置必须**逐项记录**（`cmd.txt`/`env.txt` 归档）；跨轮的"提升"必须在**同一判据段、同一协议**下取得，否则只记不判。
- **样本外护栏**：任何"提升"都要在**未见 seed（501..564）**上复核过才可升级为结论（沿用章程）。
- **口径护栏**：价值网只允许经"搜索叶评估"和"MC 评分器"两条通道影响决策（已实测）；任何**新增**通道都要单独立预注册。

## 4. 成本与预测（事后对照）

- 每轮成本：采集 60 局（~2.5 h，2–4 线程）+ 训练 ~5 min + 判据评估 128 局（~3 h，8 线程）≈ **一轮 ~6 h**；⇒ 本 goal 剩余预算内可做 **2–3 轮**。
- **我的预测**：第二轮相对第一轮的**变化在 ±3pp 内（大概率不显著）**——理由是自举没有引入**外部新信息**，而我们的数据量（60 局/轮）远小于 AZ 的规模；
  ⇒ **对"达到 0.80"我仍给低概率**（当前 ~8–12%）。若第二轮反而**变差**，则记"该管线里的价值迭代不可行"。
- **"真正需要什么"**（供选路，非本预注册的判据）：把类决策从"每 5 回合一次的 rollout 菜单"升级为**学习型规划 + 大规模搜索自对弈**，
  或用**更大的网 + 更多的自对弈数据**——那是另一个量级的工程，也正是目标文本里"允许数日算力做 2–4 轮策略迭代 ⇒ 25–35%"那一档。
