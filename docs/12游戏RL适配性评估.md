# AAArena 12 个游戏：机制层面的 RL 适配性评估

> 整理时间：2026-10-10
> 方法：**两轮独立子 agent 评估 + 我逐条读代码裁决**。第一轮用 DeepSeek 路由，第二轮用 **Kimi-K3**（不同模型家族），第二轮为**盲评**（不给第一轮结论），并要求专设「反例检查」节。
> **置信标记**：`✅✅` = 我亲自读代码/算术核实过；`✅` = 两轮独立一致；`⚠️` = 仅一轮说法或存在未决分歧。

## 0. 结论先行：为什么不该用"适配度 1-5"这一个数字

两轮共 12 个游戏，出现了 **6 处评分分歧**：

| 游戏 | 第一轮 | 第二轮 | 分歧性质 |
|---|---|---|---|
| Pacman | 2 | **4** | 准则不同 |
| LostSpace | 4 | **2** | 准则不同 |
| Generals | 3 | **2** | 权重不同 |
| Rollman | 5 | **4** | 权重不同 |
| LOTA | 3 | **2** | 权重不同 |
| AntWar2 | 3 | **2** | 权重不同（且第一轮有事实错误） |

**除了 AntWar2 那处，其余分歧全部不是事实分歧**，而是"把不同准则压成一个标量"造成的——例如 Pacman 的第一轮把「不适合确定性 MCTS」当成了「不适合 RL」。

**所以本文的主表是「游戏 × 方法族」矩阵，而不是单一分数。** 方法族的推荐两轮**高度一致**（见 §1 的"两轮一致"列），这部分才是可靠结论。

另外三轮独立得出同一结论：**"动作空间大 ⇒ RL 难"是错的**。最好的反例是 Pacman（只有 16 个动作，仍是困难游戏）与 LOTA（名义 ~10¹²，评分反而更低）。真正的驱动轴见 §2。

**读表的三个要点**

1. **AlphaZero/MCTS 只在"完全信息 + 确定/近确定 + 有前向模型"的游戏里推荐**：SnakeGo、Miracle、Generals。AntWar/AntWar2 只适合做**短视距战术层**（512 步视距下浅搜无信息）。
2. **只有 4 个游戏需要"特殊武器"**：LostSpace（league/PBT 是必需项，不是加分项）、AquaWar（不完全信息族）、LOTA（分层 RL）、Dorado（因子化/分层）。
3. **DQN 族生存空间很窄**：只在"定长小离散动作"的 Rollman / Pacman 里可用；其余 10 个游戏的动作都是变长多操作，`argmax over Q` 不成立。

## 2. 四条真正的驱动轴（替代"动作空间大小"）

| 轴 | 含义 | 命中的游戏 |
|---|---|---|
| **① 可观测性** | POMDP / 隐藏历史依赖状态 | AquaWar（隐藏身份+敌ATK被代码注释掉）、Dorado（迷雾+地势遮挡）、MoneCraft（战争迷雾）、LOTA（迷雾+隐身）、LostSpace（浅，同层全可见）、**AntWar2（信息素不下发且不可重建）** |
| **② 非平稳性** | 同时博弈 / 第三方 NPC / 多玩家名次报酬 | **同时行动**：Rollman、MoneCraft、Pacman、Dorado、LOTA、AquaWar(PICK)；**NPC**：LOTA（第三阵营野怪）、Dorado（NPC 阵营）；**多玩家**：LostSpace（4 人名次制） |
| **③ 信用分配长度** | 终局稀疏 vs 稠密、步数 | 稀疏：Generals(500)、**AntWar(512，有实测：打满上限、`avg_hp_diff=0.83`)** / AntWar2(512，结构同构但**无实测**)、LOTA(1000, 拆 1000HP 塔)、Dorado(1000)；稠密：Pacman、Rollman、Miracle、MoneCraft |
| **④ 动作悬崖** | 非法动作的后果 | **判负**：SnakeGo、Generals、AntWar、AntWar2（默认 config）、AquaWar；**静默忽略/修正**：Pacman（修正）、MoneCraft、LOTA、Dorado；**跳过**：Miracle 主阶段 |

**关键洞察**：轴 ④ 是**纯负面**的性质——"一条非法操作 = 整局输"不会带来任何学习收益，只会让早期样本全是自毁轨迹。所以凡命中 ④ 的游戏，**合法掩码是硬前提**（SnakeGo / AquaWar / Generals / AntWar / AntWar2）。

## 3. 逐游戏机制卡片

### 3.1 SnakeGo（26届）— 两轮 4/5 ✅
- **动作**：`✅✅` **6 个零参数整数码**（1-4 移动 / 5 FIRE / 6 SPLIT）。但一回合是**变长有序序列**：后端按固定顺序让 0-4 条存活蛇各提交一个动作（SPLIT 会新增蛇并插入同回合剩余序列 → 联合动作 6¹→6⁴ 放大 216 倍）。
- **观测**：`✅` 完全信息（整张 wall/snake/item map + 双方全部蛇坐标，`adk.hpp:265-274`）。
- **博弈**：严格交替、2 人零和、≤512 回合、决策点 ≤2048/方、平分判 P0。
- **奖励**：每回合可重算的**连续领地分差**；但真分靠 `solidify` 的 floodfill 闭合区 → **不可局部近似**。
- **随机**：`✅` 唯一随机源 = 道具表，开局全量下发 ⇒ 实际确定。
- **悬崖**：`✅✅` 回头 / 无道具 FIRE / 超 4 蛇 SPLIT → `raise PlayerError(ErrorType.IA, ...)`（`operate.py:247-248` 等）**立即判负**；撞墙/撞蛇只死该蛇不判负。**无 pass**。
- **时限**：3 s/回合。
- **机制硬障碍**：动作悬崖（掩码必需）+ SPLIT 的变长序列 + "圈地=自杀"的长时延权衡（蛇 solidify 后消失）。
- **文档冲突**：无重大冲突。

### 3.2 Miracle（24届）— 两轮 4/5 ✅
- **动作**：单操作 ~3×10³（summon 3卡×3星×≤17 出兵点；move ≤24 单位×≤91 可达格；attack ≤650；use ≤281）；另有选卡决策 4 神器×C(7,3)=140。
- **观测**：完全信息，每步下发 map+players（单位 18 字段）；唯一隐藏 = **选卡互盲**。
- **博弈**：交替、2 人零和、100 半回合、平局后手 +1、无 NPC。
- **奖励**：连续 score = 伤神迹×1000 + 击杀×等级 → 稠密，但**目标极窄**（打神迹主导，清兵只值 1-3 分）。
- **时序**：`✅` **每操作一帧、回合内闭环**（这是它比 Generals 好的关键）。
- **非法**：主阶段跳过不判负；**选卡阶段非法判负**（第一轮只说了前者）。
- **机制硬障碍**：回合内变长有序序列的信用分配 + 行动权耦合（每单位每回合 1 移 + 1 攻；且 `Data.json` 里 agility 全 false ⇒ 文档写的"迅捷"机制**从不激活**）。

### 3.3 Rollman（29届）— 分 5/4 ⚠️
- **动作**：`✅✅` `Discrete(5)`（吃豆人）与 `MultiDiscrete([5,5,5])`（3 只幽灵联合 = 125）；联合 625。零参数、定长、无前缀依赖。撞墙不非法（原地不动）；格式错/角色错 → IA + 扣分。
- **时序**：`✅✅` **同时行动**（一次 `step(pacman_action, ghost_actions)`）→ **12 个游戏里唯一的同时行动博弈**、闭环。
- **观测**：完全信息，但每步只发"双方动作回显"，局面须**自建前向模型**。随机全在 reset（关卡生成）且进观测。
- **奖励**：**每步稠密**（吃豆 +1/+2、被抓 -60、破盾 +10、抓人 +50、里程碑 +50、提前通关 `(MAX_ROUND-round)×0.43`）。
- **结构**：**非对称双角色**（吃豆人 1 维 vs 幽灵 3 维，目标不同）；非严格零和（常数和）；三关 500/400/300 回合；棋盘 **41/32/22**。
- **机制硬障碍**：**同时行动 ⇒ 需要混合策略/自博弈**，不是动作空间问题。
- **文档冲突**（我已逐条核实 `✅✅`）：`PACMAN_HUGE_BONUS` 是**连续存活**达阈值而非"吃豆 100"；抓捕判定用**曼哈顿距离**而非欧氏；棋盘尺寸不符。

### 3.4 Pacman（legacy·第25届同代）— 分 2/4 ⚠️⚠️
- **动作**：`✅✅` `Move{direction 4, step∈{1,2}, set_mine 2}`；普通态被强制 step=1 ⇒ **实际 8**，加速态 16。定长单动作。**无掩码**：非法输入被 `justify_move` **静默修正**（方向越界用上步方向、撞墙 step 递减到 0 = 原地）。
- **观测**：`✅✅` **近完全信息**（整图 + 双方玩家含对手分数 + 全部怪物 + 全部雷；`Game` 结构体全量发送）。唯怪物内部方向与玩家 `previous_direction` 不进观测 → **弱非马尔可夫**。
- **随机**：`✅✅` `srand(seed/time)`；`Monster::birth_dir = rand()%4`、`Player::previous_direction = rand()%4`、怪物随机游走。**随机性经怪物位置进入观测**。
- **博弈**：**同时行动**、2 人零和、600 回合、负分提前终局、等分平局；4 只固定策略随机怪（平稳，"第三方"但非决策者）。
- **奖励**：**连续稠密**（豆 +1、金宝 +5 附 10 回合加速、杀怪 +10、被杀/踩雷 -20）；豆 40 回合重生。
- **机制硬障碍**：随机怪物高方差 + `-20` 悬崖（一次失误抵 20 步）+ 同时行动。
- **两轮分歧的本质**：第一轮判 2/5 的理由是"隐藏随机性 ⇒ 确定性 rollout 失效"——**这是"不适合 MCTS"的方法特定结论，被误用成了总体评分**。对 model-free RL（PPO/DQN）这些都不致命。**建议采信 4/5**，但给 AZ/MCTS 打 ⚠️。

### 3.5 MoneCraft（legacy）— 分 3.5/3
- **动作**：`✅✅` `Action{move 6 枚举(含 Stop/Blink), blink_pos, setOB 2, buy_protect 2}`；名义 6×961×2×2=23064，但 **blink 合法目标只有欧氏 <2.9 的 25 格（去自身 24，我算术验过 `✅✅`）** → **有效 ≈ (5+24~25)×4 ≈ 116~120**。定长单动作。
- **观测**：**战争迷雾 POMDP**——每回合只发视野格（其余置 `UNSEEN`）；视野 = 矿点 3×3 + 己方玩家/观测器四向射线；**矿点恒可见且矿进度公开**（部分抵消隐藏）。
- **博弈**：同时行动、2 人零和、**1000 回合无提前终局**、胜负链 金→矿数→平局、无 NPC。
- **奖励**：每矿每回合 +10 金（稠密）；占矿 `own_point` 渐进 ±5 阶跃。
- **随机**：随机地图（重摇至 6 矿可达且中心对称）+ 双方同踩中立矿 `rand()%2`。
- **非法**：静默忽略（且不影响同回合购买）；进程错误判负。
- **机制硬障碍**：迷雾下的对手建模 + 随机地图泛化 + 占矿阶跃/硬币噪声 + blink CD = `5+3×矿数` 的"扩张-机动"负耦合。
- **文档冲突**：`rules.md` 说的"放置地雷"实为 **Observer 侦察者**（无伤害）；**摘要对迷雾只字未提**（最大遗漏）；未提随机地图。

### 3.6 AntWar（27届）— 分 3.5/3
- **动作**：9 操作 + HOLD；建塔 **33 格/方**（`✅✅` 我数过 `tower_blocks`）；升级 ≤33×3（无 Producer）；降级 ≤33；4 武器各 361；**原子 ≈1.6×10³**。变长有序列表，帧上限 2048 B。**掩码后常态只剩 10-50**（收入仅 1/轮，塔价 15×2ⁿ）。
- **观测**：帧含 round / 塔(id,player,x,y,type,cd) / 蚁(id,player,x,y,hp,level,`age=path_len`,status) / coins / 基地 hp。**不下发**信息素、升级等级、武器 CD、activeEffects、护盾——**但全部可推导**。
- **随机**：`✅✅` **整个后端 0 处 `rand()`**；移动是**确定 argmax**（`aco.cpp` 的 `eta()` 只返回 {1.25,1.0,0.75}）。唯一随机在初始信息素。
- **可重建性**：`✅✅` AI 模式的 init 帧只发 `id + random_seed`（信息素只发给人类模式）。因为移动确定 + 种子已知 ⇒ **整局位精确可重放，信息素可完全重建**。
- **博弈**：2 人零和、**轮内序贯**（P1 能看到 P0 同轮操作）、512 回合、tiebreak 链到底 P0 胜、无 NPC、地图镜像对称。
- **奖励**：终局二值（1/0）；中间量 基地 HP / 击杀 3-5-7 / 到达 +5。
  - **`✅✅` 实测 —— omegafantasy 自己的 500 局自对弈**（`saiblo-30th-AI/past_AIs/antwar_stats_summary.json`，报告见同目录 `antwar_behavior_analysis.md:3-18`，AI 版本写明是 `past_AIs/ANTWar-AI/main.cpp` = 20K 节点/150ms 树搜索）：`total_matches=500`、`p0_wins=213`、`p1_wins=240`、**`ties=47`**、**`avg_rounds` 正好 = 512（全部打满上限）**、**`avg_hp_diff = 0.83`**。
    ⇒ **500 局没有一局把基地打爆，胜负全靠超时时的 HP 净差，而平均只差 0.83 点。** 这是"长视距 + 极稀疏终局"最直接的实测证据。
    - ⚠️ 两点保留：① 该日志把 47 局记作 `ties`，但官方判据在完全相同时**判 P0 胜、不存在平局**，所以这里的 "tie" 最可能是"基地 HP 相同"，**该文档没有给定义**；② **这是 AntWar 的数据，不是 AntWar2 的**。
    - 附带一条独立印证：同一份报告算出 **P1 胜率比 P0 高 5.4%**，作者归因于"**后手能看到先手本回合的操作再决定**"——这正是我们在 §3.9 里从 `game.cpp:2683-2684` 读到的"轮内序贯"结构。
- **悬崖**：非法即判负，且**没有忽略模式**。
- **机制硬障碍**：变长有序动作 + 非法判负 + 需自建状态重建（裸帧不含信息素/等级/武器 CD，无记忆智能体天然残疾）。
- **方法要点**：**确定性是它的红利**——ES/CEM、重模拟型规划、低方差策略评估都因此可行（这是它比 AntWar2 好的根本原因）。

### 3.7 Generals（28届）— 分 3/2
- **动作**：单步原子 **≈10⁵**（军队移动 225格×4向×num；将军移动 id×225；超武含 225×225 传送）。**整回合命令串一次性提交、回合内零反馈 ⇒ 开环**；上限 1024 B + `rest_move_step` 每回合只放 2→5 条 army_move。
- **观测**：完全信息，但只初始化给全量图/将领/资源，之后**只转发对手命令串，须自行复算**。
- **随机**：运行时零随机（仅开局地形且进观测）⇒ 模型可精确复刻。
- **博弈**：交替、2 人零和、**500 回合**、tiebreak 兵力→领地→金币、无 NPC。
- **奖励**：二值，中间量须自做。
- **悬崖**：**任一非法命令立即判负**。
- **机制硬障碍**：**开环**（回合内无反馈，等于要一次规划一整轮）+ 严罚 + 稀疏 + 经济/军事时机跨百回合兑现。
- **方法要点**：两轮都推荐 **AlphaZero 式精确模型自对弈 MCTS + 自回归动作头**（因为确定性 + 完全信息 + 有前向模型），而不是 model-free。

### 3.8 LOTA（legacy）— 分 3/2
- **动作**：`PCommand = vector<Operation>`，`Operation{id, typeId(25 种), targets}`。**`Move` 是一个 4 连通变长路径**：`✅✅` `Unit::checkMoveCmd()` 强制路径起点为自身位置、逐段要求 `dis2==1`、可站立、高差 ≤1，总长超过 `sqrt(Speed)` 就 `resize()` 截断。⇒ **单单位有效 ≈10³**，联合名义 ≈10¹²。
  - ⚠️ **第一轮曾把它当成"单个坐标（151×151=22801 选 1）"，算出 ~10²³——错 10 个数量级，已纠正。**
- **观测**：**迷雾 + 隐身 POMDP**（视野 = 半径 144 的欧氏圆 + 高差 ≥2 遮挡；`Hided` 单位需 Detector 才可见）；地形 151×151 开局全发。
- **博弈**：**3 玩家 3 阵营**（P0/P1 + 第三方 NPC 野怪阵营，固定仇恨表）；**同时行动**；1000 回合；胜负 = **先破对方两座塔**（id 10-13），平局 tiebreak 塔数→塔总 HP→阵营总经验。
- **奖励**：**终局近二值、稀疏**；中间量丰富（野怪经验、塔 HP、等级）但判据只看塔；**英雄死亡只复活不输** ⇒ 信用分配极难；随机策略几乎拆不掉 1000 HP 的塔（塔会自动反击）⇒ **终端信号近乎不可达**。
- **随机**：≥5 处（buff 抽样、塔/泉随机选目标、单位碰撞 `rand()%2`、NPC 洗牌）。
- **非法**：静默丢弃 / 技能哑火，不判负；AI 超时或崩溃才判负。
- **时限**：`✅✅` **人类选手 0.1 CPU s/回合**（NPC 1.0 s，`ActMakerWeb.cpp:13-16`）——12 个游戏里最紧。
- **机制硬障碍**：变长路径 × 多单位 + 迷雾/隐身 + NPC 非平稳 + 1000 步稀疏终端 + 0.1 s。
- **方法要点**：**分层 RL（宏观选项 + 微观 PPO）+ 自博弈**；纯 AZ/MCTS 不可行；建议先做 IL 预训练（NPC 的规则策略可作 BC 源）。
- **文档冲突**：`rules.md` 说"兵线沿固定路线前进"——**代码里根本没有小兵**；说"摧毁主基地"——实为**先破两塔**；tiebreak 项不符；未提 NPC/迷雾。

### 3.9 AntWar2（30届）— 分 3/2 ⚠️（**含第一轮的事实错误**）
- **动作**：9 操作 + HOLD；建塔 **33 格/方**（`✅✅`）；升级 ≤33×4（`building.h` 17 种塔，`upgrade_type_check` 是 `new_type/10 == 当前类型`：Basic→4 选、二级→3 选）；降级 ≤33；4 武器各 361（`✅✅` 只查边界）；**原子 ≈1.6×10³**，其中 **1444 是武器坐标**——`⚠️` 但其中**绝大多数战略等价**（CD 25-45 轮、单价 60-135 ⇒ 一局人均放 ~5 次）。掩码后常态 **10-50**；`✅` 实测 **HOLD 占 66.3%**（**你自己的**实测：[`docs/goal_register.md:609`](goal_register.md) 的 6,249 次 MC 决策首次直接观测）。
- **观测**：帧含 round / 塔增量（**含 hp**）/ 蚁（含 behavior,kind）/ 双方 coins / camps（含 speedLv,anthpLv）/ **双方武器 CD + activeEffects** / 对方操作。
  **`✅✅` 不下发（且这是第一轮的错）**：**信息素 2×19×19** —— AI 模式的 init 帧只发 `id + 种子`（`comm_judger.cpp:170-171`），**信息素只发给人类模式**（`:179`）。另有蚁护盾/闪避层/target/last_move、RNG 态。
- **可重建性**：**不能** —— 种子里然下发，但蚂蚁移动是**每步随机采样**，要位精确重放需复现整个 LCG 调用流，实践上不可行 ⇒ **实质是"带隐藏历史依赖场（信息素是轨迹的衰减积分）的 POMDP"**。
- **随机**：`✅✅` 6 个源：初始信息素 U[8,12)、出兵 profile 抽样 {0.4,0.35,0.10,0.15}、**每 10 轮传送 10% 蚂蚁**、武器中心每轮漂移、**每只蚂蚁每步 softmax(τ=1.75) 采样移动**、魅惑塔随机目标。
- **博弈**：2 人零和、**轮内序贯**（P1 可见 P0 同轮操作 ⇒ P1 有轮内信息优势）、512 回合（`✅✅`）、tiebreak 链含 **"AI 总耗时少者胜"**（机制上惩罚慢决策）、同轮双归零 P0 胜、无 NPC、镜像对称（`⚠️` `game.yaml` 标 `roles_symmetric:false` 的理由"基地位置不同"不成立，真正不对称只有 P0 先动）。
- **奖励**：终局二值、中间没有可读的标量。⚠️ **AntWar2 本身没有实测数据**——我原先在这里引的"500 局统计"其实是 **omegafantasy 的、而且统计的是 AntWar(27届)**（正确出处见 §3.6）。只能说 AntWar2 的 512 回合上限与 tiebreak 链（HP→击杀→武器数→耗时）与 AntWar 同构，**结构上很可能也是"超时 1 HP 净差"**，但这是推断、没有 AntWar2 的实测支撑。
- **配置陷阱**：`cold_handle_rule_illegal`（默认 false = **非法即判负**）与 `movement_policy`（legacy/enhanced）会改变语义 ⇒ **训练与评测必须先钉死 config**。
- **机制硬障碍**（四点叠加）：**非法即判负的悬崖 + 变长有序动作 + 每步高方差随机 + 帧序列非马尔可夫（信息素不下发且不可重建）**。
- **文档冲突**：31/32 升级花费；`:54`"被拒操作记录"与 `:66`"非法→game_error"自相矛盾（对应两种 config 而文档未注明）；升级 `args` 校验漏洞（不存在的类型被静默接受）。

### 3.10 AquaWar（25届）— 两轮 3/3 ✅
- **相态机**：`READY → PICK → ASSERT → FIGHT`（`aqua_sdk.cpp:328-351`，`✅✅`）。所以两轮"同时 vs 交替"的分歧是**各说了一半**：PICK 是同时盲选、战斗是交替。
- **动作**：按阶段——PICK 帧 **5×10⁴**（12 选 4 有序 + 拟态）；ASSERT **49**；普攻 **16**；技能原始 1024、有效 5-40。
- **观测**：**隐藏身份 POMDP** —— 敌鱼种 id 只有**断言命中才暴露**（`is_expose` 的唯一写点 = 断言成功；死亡/技能都不暴露）；**敌 ATK 的构造被代码注释掉了**（主动封死"从攻击力反推身份"的捷径）；敌鱼池不可见。**但敌行动的技能 type 字符串 + 伤害值会转发 ⇒ 行动是身份泄露通道**。
- **博弈**：2 人零和；单小局 `STATE_LIMIT=128`；**总打满 3 小局**（`round_end` 只在 `rounds==3` 触发）；裁定链 活鱼→总血→单血→后手。
- **奖励**：**断言 = 双向赌注**（命中：敌全队 hp-50 + 暴露一条；失手：**己方全队 -50 且一无所获**）⇒ **信息本身是可消耗资源**。
- **随机**：`✅✅` **不可播种** —— `fish.cpp:17-23` 用 `gettimeofday().tv_usec` 播种（`srand` 全被注释），3 种鱼 30% 闪避 ⇒ **破坏 CFR 的精确反事实**。
- **非法**：一切非法 = 整场判负，无静默修正。
- **机制硬障碍**：信念推断（且捷径被封）+ 不可复现随机 + 信息作为资源。
- **文档冲突 ×3**：`rules.md` 说鱼种"因技能/死亡而暴露"（伪）、"不消费随机种子/结果一致"（伪）、"先胜 2 局即止"（伪，实际必打满 3 局）。

### 3.11 LostSpace（25届）— 分 4/2 ⚠️
- **动作**：单决策点 **≤15**（上界 174）；回合内变长序列（`sp=1` ⇒ 1 个耗 sp 动作 + 若干免费动作）。
- **观测**：**部分可观测但很浅** —— `✅✅` `can_see` 就是 `return int(pos1.z == pos2.z)`（**无距离限制、无遮挡，同层整层可见**，代码注释："仅提供同层视野，但同层视野都可见"）；其他三人只给 `brief_dict = {id, status, keys, hp}` ⇒ **看不到位置、道具、陷阱**；异层完全不可见。
- **博弈**：`✅✅` **4 人、严格交替（固定轮转 P0→P1→P2→P3）、排名制非淘汰**；名次分 **4/3/2/1 恒和 10 = 常和非零和**（`GameController.py:390 score_dic[...] = 4 - i`）；≤100 大回合；前 80 回合死亡可复活。
- **随机**：**零随机**（固定地图）。
- **奖励**：名次分（有 partial credit，不是 winner-take-all）；击杀 +2 / 死亡 -3 掉包 ⇒ **合作/背叛空间存在**。
- **对称性**：`✅✅` `game.yaml` 声明 `roles_symmetric: true`，但同分时**后手优先**（`:379-381` 注释"后手在前" + 稳定排序 `reverse=True`）⇒ **实际存在方向固定的先/后手偏差**。
- **机制硬障碍**：**4 人非平稳**（名次报酬 + 合作/背叛）⇒ **league/population-based 是必需项**。
- **两轮分歧的本质**：两轮**机制描述一致**，分歧只在"必须 league training"该扣多少分——第一轮给 4/5，第二轮给 2/5。这正是 §0 说的问题。

### 3.12 Dorado（legacy）— 两轮 2/2 ✅
- **动作**：`PCommand` 变长单位命令批；**`Move` 也携带完整路径（≤√Speed 步）**（与 LOTA 同族引擎）；每单位 10²-10³ × ≤8 英雄 + 基地 ⇒ **联合空间 10¹⁰-10³⁰**；**同一单位只保留最后一条命令**（`deduplicateCmd`）。
- **观测**：**战争迷雾**（视野 r=12、**地势遮挡 `height[自己]+2 > height[目标]`** ⇒ 高看低可见、低看高不可见）；`Hided` 需 Detector；**敌方金币不可见**。
- **博弈**：**同时行动**（全员同时提交统一结算）；1000 回合；2 人类阵营 + 1 NPC 阵营（4 龙 2 Roshan，样例 AI）。
- **奖励**：基地 3000 HP 摧毁 / 1000 回合比 `countProperty`。
- **随机**：3 处（矿刷新、buff 重叠采样、碰撞位移）；种子是 `AA_ARENA_GAME_SEED`，但**样例 SDK 的 `srand(time)` 会覆盖它** ⇒ 不可复现。
- **非法**：静默忽略 / 路径截断；崩溃或超时才判负。
- **机制硬障碍**：**联合动作 × 迷雾 × 同时性 × 长视距（10³）四者叠加**（这是它两轮都被判 2/5 的原因）。

## 4. 哪些机制让"标准 RL 假设"失效（汇总）

| 失效的假设 | 命中的游戏 | 证据要点 |
|---|---|---|
| **MDP / 状态充分性** | AntWar2（信息素是历史衰减积分且不下发）、AntWar（裸帧不含信息素/等级/武器CD）、AquaWar（隐藏身份）、Dorado（迷雾）、MoneCraft（迷雾）、LOTA（迷雾+隐身）、LostSpace（浅）、Pacman（怪物隐藏方向） | 需记忆或重模拟 |
| **完全可观测** | 同上（除 SnakeGo / Miracle / Rollman / Generals / AntWar 的"重建后"） | |
| **同时行动的同步博弈** | Rollman、MoneCraft、Pacman、Dorado、LOTA、AquaWar(PICK 阶段) | 需混合策略 / self-play |
| **多智能体非平稳** | LostSpace（4 人名次制，**唯一必须 league**）、LOTA（第三方 NPC）、Dorado（NPC 阵营） | |
| **开环 → 闭环控制** | **Generals**（整回合命令串一次提交、回合内零反馈） | 一等一的开环问题 |
| **长视距 + 稀疏奖励** | Generals(500)、AntWar/AntWar2(512)、LOTA(1000)、Dorado(1000) | **AntWar 有实测**（omegafantasy 的 500 局自对弈）：全部打满 512 回合、`avg_hp_diff=0.83`、47 局 HP 相同；**AntWar2 结构同构但无实测数据** |
| **可复现性（对 CFR/重模拟）** | AquaWar（`gettimeofday` 播种，不可复现）、Dorado（SDK 覆盖种子） | 破坏精确反事实 |
| **动作是定长离散集** | 10/12 个游戏（变长多操作 / 参数化 / 路径），只有 Rollman、Pacman 是定长小集 | DQN 因此大面积不可用 |

**12 个游戏里只有 SnakeGo 完全满足标准 RL 假设**（完全信息 + 确定 + 定长小动作 + 交替）。
