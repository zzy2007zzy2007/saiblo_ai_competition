# 预注册：**Phase 0 —— "闪电被禁用"子博弈的可行性 / 信息量测量**

> 2026-10-17 写（**在跑这批之前**）。章程：`docs/task_ruleV4_90_charter.md`。
> 背景与动机见 `docs/next_step_ideas.md`（用户提出：闪电已优化得差不多，其他动作训练不足，
> 但一训就会抢金币 ⇒ 干脆**双方禁闪电**，把"经济面"孤立出来研究）。
> ⚠️ **本 Phase 不是判据**：最终判据仍是"vs `rule_v4` 两段各 128 局 ≥90%"。Phase 0 只做**环境表征**。

## 0. 已完成的机制前置工作（**跑前已验**）

1. **"禁闪电"在类掩码层实现**（不是让 AI 空过回合）：`AZAI_BAN_CLASSES=17` 作用于 `decoder.make_class_mask`
   这一唯一咽喉 ⇒ 搜索采样 / 候选枚举 / MC 菜单**全都看不到闪电**。
   另加执行层安全网 `AZAI_BAN_OPS=21`（**每次触发都记数**，>0 说明掩码禁类不彻底）。
2. **冒烟（2 局）**：我方禁闪电后 **闪电 = 0 且安全网触发 = 0** ⇒ 禁类彻底；但**动作数从 ~32/局 塌到 6.5/局**
   （`mc_quiet` 基本在"过牌"）；`playable` 则变成 **建塔 100.5 / 降级 98.5 的 churn 风暴**。
3. **对手侧**：新增两个 launcher（**不改任何原文件**）——
   `code/test_match/ex_pkg/main.py`（官方 `ExampleAgent`，`AI_BAN_LIGHTNING=1` 时可禁闪电）、
   `code/test_match/nl_pkg/main.py`（rule_v4 的禁闪电副本，子类覆盖 `get_lightning_bundle` + 兜底过滤）。
   冒烟：我方禁闪电 **0/2** 输给带闪电的 example；**2/2** 赢 rule_v4 禁闪电副本（⇒ 它退化）。

## 1. 四个问题与臂（每臂 **64 局 = 固定段前缀 `7..38`（32 对）**，`jobs=8`）

| 臂 | ai0（我方） | ai1（对手） | 回答什么 |
|---|---|---|---|
| **A1 镜像** | 禁闪电（`mc_quiet`）| **同一个我方 AI**（也禁闪电）| 噪声地板 + 对称性 + churn（**内部锚点**就是它）|
| **A2** | 禁闪电 | 官方 example（**带**闪电）| "我们残疾时"对通用对手的鲁棒性 |
| **A3** | 禁闪电 | 官方 example（`AI_BAN_LIGHTNING=1`）| **对称子博弈**里我们对通用对手的胜率 |
| **A4** | 禁闪电 | rule_v4 禁闪电副本 | sanity：rule_v4 禁闪电后是否**退化**（若我们 ~100% ⇒ 它不能当锚点）|

- 公共配置 = `M6c-ROOT` 原样（K=24/ITERS=256/`mc_quiet`），**只多两个禁类开关**。
- 判词必须全 engine；无效+缺失 ≤10%。

## 2. 读数（必报）

1. **胜率**（每臂 p̂ + CI）与大比分构成；
2. **成本/噪声**：对局回合数、单局墙钟、32 对的 CI 半宽（与真实对局对比）；
3. **机制**：我方 `BUILD / DOWNGRADE / UPGRADE / LIGHTNING`、有操作回合数、**升级是否仍为 0**；
4. 🔑 **churn 读数**（问题④的证伪）：`(建塔 + 降级)` 的强度与"建完就拆"的循环是否在禁闪电后**消失/减弱/爆发**；
5. 对手的机制读数（用于判断它是否退化）。

## 3. 判据（**先写死**）：Phase 0 → Phase 1 的 go/no-go

- **G1（可测）**：A1 镜像的 p̂ ∈ [0.35, 0.65]（无病态不对称）且 32 对 CI 半宽 ≤ 15pp；
- **G2（有杠杆）**：子博弈里我方**经济动作真的被用起来**（≥ **15** 个经济动作/局：建塔+降级+升级），
  即不是"过牌塌陷"；且**经济动作的多少/方式能改变胜负**（A1 与 A3/A4 的机制读数不能被对手镜像解释）；
- **G3（非退化对手）**：至少有一个对手**不是墙**（A3 或 A4 的 p̂ ∈ (0.1, 0.9)）；
- **G4（够便宜）**：单局墙钟 ≤ **2×** 真实对局（即 64 局一臂 ≤ ~30 min）。
- **四个都过** ⇒ 进 Phase 1（在子博弈里做"经济策略"的方法侧实验，锚点 = A1/A3 里最强的那个，
  之后**必须回传真实对局**在判据尺度上验证）。
- **G2 不过（任一 pin 都塌成过牌）** ⇒ 结论"子博弈需要先构造一个会干活的经济策略（手工/学习），
  当前管线在禁闪电下没有可研究的策略" ⇒ **记录并停**（不硬上 Phase 1）。
- ⚠️ 本 Phase **不作任何"采纳/晋级"判断**，64 局只用于表征；任何"正效应"都必须另行在未见样本上确认。

## 4. 预测（写下来，事后对照）

- A1 镜像：我估 p̂ ≈ 0.5（±15pp 内），但**每局经济动作很少**（过牌塌陷）。
- A4（rule_v4 禁闪电）：我估我们 **接近全胜**（它退化）⇒ G3 要靠 A3 满足。
- A3（example 禁闪电）：**不确定**——我估 p̂ ∈ [0.3, 0.7]（它是通用对手，禁闪电后未必弱）。
- churn：我估**禁闪电后 churn 依旧/更强**（冒烟里 `playable` 已经 100/98）⇒ 支持"churn 是策略缺陷、
  不是金币耦合"这一判断（即用户假设的**治病机理不成立**，但"孤立经济面"这件事仍有价值）。
