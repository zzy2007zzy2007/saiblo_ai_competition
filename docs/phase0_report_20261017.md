# Phase 0 报告：**"闪电被禁用"子博弈 —— 四个问题的答案，以及一个意外有用的发现**

> 2026-10-17/18。预注册：`docs/prereg_20261017_phase0_nolightning.md`（主批 A1–A4）
> 与 `docs/prereg_20261017_phase0_addendum_economy.md`（附录 E1–E3、A5）。
> 最终判据仍是"vs `rule_v4` 两段各 128 局 ≥90%"；Phase 0 只做**环境表征**。

## 1. 做法（"禁闪电"必须在**掩码层**，不是让 AI 空过回合）

- **我方**：`AZAI_BAN_CLASSES=17` 作用于 `decoder.make_class_mask`（唯一咽喉）⇒ 搜索采样 / 候选枚举 / MC 菜单**全都看不到闪电**；
  另加执行层安全网 `AZAI_BAN_OPS=21`，**每次触发都记数** ⇒ **实测触发 0 次**（禁类彻底）。
- **对手**：两个新 launcher，**不改任何原文件**（`code/test_match/ex_pkg/main.py` 官方 `ExampleAgent`；`code/test_match/nl_pkg/main.py` rule_v4 的禁闪电副本）。
- 全部臂：64 局 = 固定段前缀 `7..38`（32 对），`jobs=8`；判词全 engine、无效 0。

## 3. 四个问题的答案

- **Q1 胜率**：对官方 example（**无论它能不能放闪电**，它本来 0.0–0.2 次/局）我们 **0.0156（31/32 对 0-2）**；
  对 rule_v4 禁闪电副本我们 **1.0000**（因为**它退化成完全不出招**：0/0/0/0）。
- **Q2 噪声/成本**：32 对的 CI 半宽 ~11pp（无异于真实对局）；对局仍打满 512 回合；**单局 0.9–1.4 min（比真实对局 2.9 min 更便宜）**。
- **Q3 经济面有没有杠杆**：**有，但要先把它"解锁"**（见 §4）。
  主批里我方**只做 11.5 个经济动作/局、升级 0**；`MC_EVERY=1` 只把它抬到 16.4（仍升级 0）；
  **`MC_UPG=1`+`MC_TOPK=3` 才第一次让它变成"中等强度、不 churn"的经济打法**（20.2/8.7/**2.8**）。
- **Q4 关键证伪（用户的"抢金币"假设）**：**churn 与"升级 0"在禁闪电后依旧**（A1/A2/A3 的降级 = 0、升级 = 0；
  而"能花就花"的 `playable` 直接变 **100.5 建 / 98.5 降**的 churn 风暴）。
  ⇒ **去掉闪电/去掉金币竞争，并不会自动变出经济能力** ⇒ "抢金币"不是病根。

## 4. 🔑 意外有用的发现：**经济动作是被"闪电候选"在决策层挤掉的**

- 事实：`MC_UPG=1 + MC_TOPK=3`（放宽菜单）在**真实对局**里（第 3 轮）**完全没激活**（升级始终 0）；
  但在**闪电被禁**（=菜单里没有闪电）时，同一个开关**立刻让升级从 0 变成 2.8/局**，
  并把对 example 的胜率从 **0.0156 → 0.4375（+42pp）**。
- ⇒ **机理**：MC 菜单里的**闪电候选几乎总是赢**（它的安静 rollout 分数最高/最稳），
  于是经济与升级候选**永远轮不到**；**闪电一移开，它们才被公平比较**。
  这同时解释了第 3 轮"菜单加宽在真实对局里没激活"那三个阴性臂。
- ⇒ **可搬运的假设（已预注册并在跑）**：真实对局里让 **闪电不进 MC 菜单**（`AZAI_MC_NO_LIGHT=1`，
  闪电仍由非 MC 回合的默认"买得起就放"负责）+ `MC_UPG=1` + `MC_TOPK=3`
  ⇒ 经济/升级候选获得公平比较。预注册 `docs/prereg_20261018_mc_nolight_real.md`（判据尺度：两段各 128 局；
  机制闸门：**升级 > 0、闪电 ≥ 8.0/局、不 churn**）。

## 5. go/no-go 判据核对（预注册写死的）

| 判据 | 结果 |
|---|---|
| **G1** 镜像 p̂ ∈ [0.35,0.65] | ❌ **不过**（1.0000；A5 想用随机化判别但**没起作用**：A5 的动作构成与 A1 逐项相同 ⇒ **未判别**是"地图先手"还是"确定性伪影"）|
| **G2** 经济动作 ≥15/局（主批）| ❌ **不过**（11.5）；**附录 E2 过**（31.7，且升级 2.8 > 0、降级 8.7 ≤ 建塔/2）|
| **G3** 至少一个对手不是墙 | ❌ **不过**（A3 = 0.0156 是墙；A4 = 1.0 是反墙）|
| **G4** 单局 ≤2× 真实对局 | ✅ **过**（≈1 min vs 2.9 min）|
| **"解锁成功"**（附录三条）| ✅ **E2 三条全中** |

⇒ **对 Phase 1 的原计划（用"我方禁闪电自锚点 + 80%"做目标）：不成立**——
我们的策略在该子博弈里**几乎没有经济行为**（11.5 动作/局、升级 0），而且镜像**由先手决定**（1.0），
所以"打赢这个锚点 80%"既不困难也不说明问题（真实难度在 §4 那条：先把经济动作**唤醒**）。
⇒ **但 Phase 0 仍然产出了一个可搬运的机理**（§4），并且**已经按判据尺度在真实对局里验证**。

## 6. 诚实限度

1. **A5 未能判别**（`TEMP=1.0` 在本管线里没有实际效果：A5 与 A1 的动作构成逐项相同）⇒ 子博弈"是否由先手决定"**未解**。
2. **A4 截断**（25/64 局；因 rule_v4 的巨型决策日志导致 5.1 min/局）——其结论（对手完全不出招 ⇒ 我们全胜）方向明确。
3. **E3 跳过**（`playable` 单局 >10 min，触到成本闸门）——用冒烟读数（100.5 建 / 98.5 降）代替。
4. 所有数字是 **64 局（32 对）**的**表征**读数，**不构成任何"采纳/晋级"判断**（第 9 轮铁律）。
