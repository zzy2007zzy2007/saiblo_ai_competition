# 计划 + 预注册：**用"探索 + 结果加权（AWR）"把类头练成真正的花钱/省钱策略**

> 2026-10-15 第 15 轮写（**在跑之前**）。章程：`docs/task_ruleV4_90_charter.md`（大改需先写计划）。
> ⚠️ **换 ckpt = 机械门** ⇒ 若晋级须走独立验证 + 记档。

## 0. 为什么这是**唯一还剩的、量级上可能 >+10pp** 的路

| 已知事实（都有出处）| 含义 |
|---|---|
| **类头在决策路径里、影响巨大**（扰动 `class_state` ⇒ 落点一致率 **0.000**）| 类头管着 **80% 回合**的类决策 |
| 类决策是**承重**维度（无 MC `0.5000`；加密 `0.5156`；K<24 −25~−56pp）| 改对它有最大杠杆 |
| 但**类头学不出状态依赖**：第 10 轮"logit std 0.285 却 argmax 不变"；第 14 轮"visit 目标退化（=pin 本身）" | **现有目标里没有"同状态内的跨类对照"** |
| **M2 的 Q 头**：训练指标好（MSE 0.074）但部署退化成 churn —— 因为"花钱只出现在富状态"（**混淆**）| 缺的是**同状态内的对照**，不是模型容量 |
| **M3b**：50% 类探索把覆盖做到 98.9%，但识别性闸门**差一点** ⇒ **从未真正打过对局** | 探索是对的；**但从未用"对局"来判它** |

⇒ **本计划的做法**：用**随机类探索**制造"同状态内的对照"（打破 M2 的混淆），用**对局结果**加权（AWR）
去训**类头**，然后用**判据尺度**的对局来判（而不是识别性闸门）。**部署侧一个字都不用改**
（类头的 argmax 本来就决定非仲裁回合的类）⇒ **单变量 = 只有 `class_state` 变**。

## 1. 做法（四步，全部现成工具）

1. **探索采集**：`az_selfplay`（**部署配置** `mc_quiet/EVERY=5/ROOTONLY=1`、K=24/ITERS=256）
   + **`--class-pin-random-prob 0.3`**（30% 回合**随机钉一个合法类**）⇒ **80 局**
   （种子 `80,010,000+`，**与判据 seed 不重叠**，章程③）。产出 pkl（含 `value_target` = 该局终局 HP 差、clip ±1）。
2. **打标签**：`ingest_selfplay_classes.py --label pinned`（探索模式下"被钉的类"就是**实际执行的类**）。
3. **AWR 训练**：`train_class_outcome.py --beta <β> --class-weight-power 0.5`（`w ∝ exp(a/β)`，`a` = 该局结果）
   ⇒ **只产出 `class_state`**（历史已验证它只改类头；本轮仍要逐张量核对）。
4. **判据尺度评估**：**部署回到原配置**（`AZAI_CLASSPIN_RANDOM=0`，即 `M6c-ROOT` 原样；只有 ckpt 的 `class_state` 不同）
   ⇒ 跑**固定段 128 局 + 随机段 128 局**（对照 = `M6cROOT_128` / `M6cROOT_rand128`）。

## 2. 判据（**先写死**；吸取第 12/13 轮教训）

1. **机制前置判据 P1（先过）**：**部署行为必须变** —— 小批（seed 7..10，8 局）`cmp_op_cells.py` **落点一致率 < 0.8**，
   **且报类的占比变化**（我方 op 里 BUILD/DOWNGRADE/LIGHTNING 的构成）。
   ⚠️ **同时报"argmax 类分布"的前后变化**（第 10/14 轮的教训：只看 CE/logit 指标会被骗）。
   **P1 不过 ⇒ 不作结论、直接关闭**（不追加数据）。
2. **主判据（判据尺度）**：
   * **两段都非负** 且 **合并 ≥ +3pp** ⇒ **候选**；
   * **两段都 ≥ +8pp**（或合并 ≥ +8pp 且无一段为负）⇒ 进**两段 128 局验收 + 独立验证 + 机械门**；
   * 一正一负，或合并 < +3pp ⇒ **不采纳**（记档）；合并 ≤ −3pp ⇒ **关闭该轴**。
3. **有效性**：无效+缺失 ≤ 10%，判词全 engine。
4. **止损线（事先写死）**：若 P1 通过但**两段合并 ≤ 0**，**不再追加数据/不调 β**，直接记"此路在本预算下无效"并关闭。

## 3. 成本

| 步 | 成本 |
|---|---|
| 探索采集 80 局 | ~1.5–2 h（K=24、8 workers）|
| 打标签 + AWR | ~10 min |
| P1 小批 | ~5 min |
| 判据尺度评估（两段 256 局）| ~2 h |
| 合计 | **≈ 4 h** |

## 4. 预测（写下来，事后对照）

- **P1**：**通过的概率 ~60%**（探索数据把类标签变得更多样 ⇒ AWR 会移动 argmax；但也可能"平均回 pin"）。
- **P2（主判据）**：**合并 ≥ +3pp 我给 ~30%**、**≥ +8pp 我给 ~10%**。
  ① 正面：这条**第一次**给了"同状态内的跨类对照"（探索）+ 结果加权（M2/M3b 从未打过对局就停了）；
  ② 反面：**结果信用分配极噪声**（一局的结果由上千个决策决定）；且历史 Q 头/BC 线的教训是"指标好看、棋力不动"。
- **P3**：若 P1 通过（决策确实变了）而棋力**显著变差** ⇒ 说明"用结果加权学类"在**这个动作空间**里会学到
  **过度花钱**（与 E-2/F_upg/建塔门槛的教训一致）⇒ 记入"花钱轴"的第四例反证，彻底关闭该维度。
