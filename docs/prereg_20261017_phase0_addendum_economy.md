## 0. 已有读数（Phase 0 主批 + 冒烟）

| 事实 | 数值 |
|---|---|
| 真实对局我方 | 建塔 **24.8** / 降级 10.9 / 升级 0 / 闪电 10.5（每局）|
| **禁闪电后我方**（`mc_quiet`）| 建塔 **11.5~11.8** / 降级 0 / 升级 0 / 闪电 0 ⇒ **比真实对局建得更少**（不是"省给闪电"）|
| 禁闪电后换 `playable` 钉法 | 建塔 **100.5** / 降级 **98.5** ⇒ **churn 风暴** |
| 官方 example（禁闪电与否都一样）| 建塔 **33.1** / 降级 13.1 / 升级 **6.0** / 闪电 0.0 ⇒ **稳定经济打法**，把我们打成 **31/32 对 0-2**（`p̂=0.0156`）|
| A1 镜像（我方禁闪电 vs 我方禁闪电）| **`p̂ = 1.0000`（32 对全 2-0）** ⇒ 先手在子博弈里被放大到 100%（真实对局：执先 76.6% / 执后 67.2%）|

⇒ **两种解释**（用户假设 vs 我们的机制解释）：
① 用户假设："决策仍在为闪电留币" ⇒ 那就该**建得更多**才对，但实测**建得更少**（24.8→11.7）；
② 我们的解释："**决策机器没有经济策略**"——非仲裁回合的默认类本来是闪电脑 argmax（禁掉就塌成 HOLD），
   MC 少了一个候选、其安静 rollout 在"建塔 vs HOLD"上常打平（平局按顺序给 HOLD）。
⇒ 但**"解开限制能让它动"确实成立**（`playable` 就动得很凶）⇒ 缺的是**中间那个"有目的地花"**。

## 1. 臂（每臂 **64 局 = 前缀 `7..38`**，`jobs=8`；我方一律 `AZAI_BAN_CLASSES=17`+`AZAI_BAN_OPS=21`）

## 2. 读数与判据（**先写死**；本批仍是**表征**，不作采纳判断）

必报：我方 `建/降/升` 每局、有操作回合、对手同项、对局回合、单局墙钟、无效数、`p̂`。

- **"解锁成功"**（三条同时满足）⇒ 值得进 Phase 1：
  ① 经济动作 **≥ 25/局**（不再过牌塌陷）；② **升级 > 0**；③ **不 churn**（降级 ≤ 建塔/2）。
- **"解锁失败"**（任一条不满足且无臂满足）⇒ 结论：**本管线没有"中等经济"工作点**
  （要么过牌、要么乱花）⇒ 经济面需要一个**新的策略组件**（而不是一个旋钮）⇒ 记录并停止 Phase 1 的推进。
- **A5**：`p̂ ∈ [0.40, 0.60]` ⇒ A1 的 1.0 是**确定性伪影**（子博弈本身不算退化）；
  `p̂ ≥ 0.80` ⇒ 子博弈**确由先手决定** ⇒ 作为研究靶场也不合适。
- ⚠️ 64 局只作表征；任何"更好"的说法都要另行未见样本确认 + 回传真实对局（判据尺度）。
