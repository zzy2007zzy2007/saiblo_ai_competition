## 怎么读这张表（**它不是权威；允许、而且鼓励被推翻**）

1. **每条都是"当前最佳解释"，不是事实。** 尤其"解读"部分：同一组读数可以有不同解释，
   而解释会受**当时提问方式、已有信念、以及我的主观性**影响。**明确把"读数"和"对读数的解读"分开**：
   读数（命令 + 输出）通常可复核；**解读是判断，推翻时多半推翻的是它**。
2. **实验有随机性** ⇒ 看 **n / 是否配对镜像 / SE**。**n 小或单次的一律标"弱"**，
   不许当成定论用（项目史上"单臂排名在轮次间完全不可复现"）。
3. **允许推翻，而且推翻不是异常操作。** 本文件的历史里就发生过：同一天我对"对局是否确定"
   连翻两次结论（先判"CPU 争抢"、再判"确定"、最后实测为"不可复现"）。**推翻要照同一条纪律走**：
   写清原结论的**可能失效点** + 用预注册判据重做 + 记档。
4. **"已排除"的正确读法**不是"永远排除"，而是"**在没有新证据或新理由之前，不值得再试**"。
   所以重开它的门槛是两问：① 当初那条判据**哪里可能失效**？② 这次的做法**哪里不同**？
5. ⚠️ **强度标记的含义**（每行必标）：

   | 标记 | 含义 |
   |---|---|
   | **强** | 多套独立读数方向一致，或用**逐字段级**比对、可复核 |
   | **中** | 单批内聚合、配对，n 中等；方向可信但幅度不可靠 |
   | **弱** | 单次 / 小 n / 未配对 / 只是机制读数 ⇒ **不能当定论** |
   | **存疑** | 已有反面证据，或曾被推翻过一次 |
