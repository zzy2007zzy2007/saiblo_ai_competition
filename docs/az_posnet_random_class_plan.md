# 修改方案：位置-only 阶段的"随机钉类"（让位置网的所有通道都能被训练）

> 日期：2026-09-16。用户提出。状态：**计划阶段，待过目。**
> 前置：`docs/az_three_net_split_plan.md`（三网拆分）、`docs/az_action_factorization_idea.md`

## 1. 动机（两个实测事实）

### 1.1 现在的位置网其实只训了 1 个通道

对 `posnet_p2/compact`（400 局 / 9367 个位置样本，取前 200 局 4694 个）统计位置目标的
**质量落在哪些类上**：

```
class 17: 100.0%          涉及的不同类数 = 1 / 24
```

⇒ pos-only 把类钉在 `argmax`（= 闪电），于是**位置 CE 只作用于 `action_map[17]` 一个通道**；
其余 23 个通道从未被训练过，只被 anchor 维持在原值。

### 1.2 闪电实际上被"冷却"卡住，且它就是全部的位置数据

`az_progress_seed9101010000.txt`（437 轮）：

```
有动作的轮次 24/437 = 5.5%      动作总数 48（双方），其中闪电 24 次
```

而 23.4 个位置样本/局 ≈ **24 次闪电使用** ⇒ **整份位置数据集 = "闪电该往哪儿放"**，一一对应。
闪电平均每 ~18 轮放一次（像"冷却一好就放"）⇒ **金币不是限制，冷却才是**
（所以"对局动起来→金币多→闪电买得起"这条推测不成立）。

## 2. 改动定义

在 pos-only 搜索里，**以概率 p（按头独立）把"钉住的类"从 `argmax` 换成一个均匀随机的
合法类**，然后照旧只在该类上搜位置。其余行为不变。

```
pinned_head[h] = argmax(head_logits[h])                       # 概率 1-p（现状）
               = uniform{ c : class_mask[c] 且 c != HOLD 且 position_mask[c].any() }   # 概率 p
```

- **必须带位置**：`position_mask[c].any()` 为假时（基础升级 21/22）钉了也产不出位置目标，白费；
  HOLD(23) 同理。
- **按回合的有效率**：单头概率 p ⇒ 一回合至少一个头被随机的概率 ≈ `1-(1-p)^3`（p=0.05 → 14%）。
- **不是"把随机动作当策略"**：这与 `--random-action-prob`（均匀随机 bundle）不同——
  这里**类随机、但位置仍然由搜索做价值排序**，所以产出的目标是"**该类在该局面下该放哪儿**"
  这一有意义的问题的答案（今天的控制实验已证价值头会排位置：随机位置 0/32、价值选中 90.6%）。

## 3. 先验预期（写下来，免得事后顺着结果编解释）

| 项 | 预期 |
|---|---|
| 通道覆盖 | 从 1/24 变成以 **0-16 号通道**为主（塔类 0-15 + 降级 16）。**超武 17-20 只在买得起时才走 `action_map[17..20]`**，否则走降级通道 16 ⇒ 超武通道仍难覆盖 |
| 位置样本量 | 期望从 23/局 明显上升（具体倍数未知） |
| 对局 | 更有动作、更决定性（顺带治被动性），但**状态分布偏离部署分布**（见风险） |

## 4. 与既有机制的关系

- **anchor**：不变（目标仍是采集时记录的 `action_map`）。但注意：对那些"从不被使用"的通道，
  记录值就是旧原值，而 CE 想把它们改掉 ⇒ **anchor 现在会反对新通道的学习**。
  λ_anchor 的取值因此更需要实测（Phase 2 里 λ=30 ≈ 有效比 1%，λ=150 ≈ 5%）。
- **`filter_pos_samples.py`**：不用改（它按"该样本是否有位置目标"过滤，被注入的样本天然满足）。
- **`az_train.py`**：不用改。
- **`eval.py` / 镜像台**：不用改——**评估时不开随机**（保持确定性），随机只用于采集。

## 6. 判据（跑之前写死）

1. **通道覆盖**：`report_channel_coverage.py` 显示涉及类数从 1 → 十几个，且分布不塌在单一类上；
2. **位置样本量**：过滤器打印的"X 样本 (Y%)"明显高于 9367 / 2.8%；
3. **镜像判据（关键）**：训练后 **vs 第 0 轮**的 raw 镜像配对（该台 SE=0）**不能变差**
   ——因为闪电通道是我们唯一在用的功能，它退化就没有意义了；
4. （辅助）对局的动作轮次占比从 5.5% 上升。

## 7. 实验设计（最小成本的干净对比）

等现在的 `posnet_loop` 跑完，取它**最后一个 ckpt** 作为起点，**同一批 seed**跑两条平行分支
（各一轮采集+训练）：

- **A（对照）**：照旧（`pos-pin=argmax`）；
- **B（随机钉类）**：`--class-pin-random-prob p`。

两边起点、种子、训练超参完全相同 ⇒ 差异只来自这个改动。比 §6 的判据 1-3。

## 8. 已定 / 待定（2026-09-16 用户确认）

### 已定

1. **随机粒度 = 按头**（每个头独立，符合"每个头是独立决策"）。
2. **p = 0.01（按头）** ⇒ 回合级 `1-(1-0.01)^3 ≈ 2.96%`。

   **校准依据**（`docs/experiment_log.md` §"2% / 5% 随机动作注入消融"，`az_p6` vs rule_v4、
   同 seed 0-31 配对）：

   | 注入率（每决策）| 战绩 | 胜率 |
   |---|---|---|
   | 0 | 9W/23L | 28.1% |
   | 2% | 13W/19L | 40.6%（p≈0.45 不显著）|
   | **5%** | 3W/29L | **9.4%（显著有害 −19pp）** |

   原文结论："每 20 步 1 次乱走就能让 5% 的配置掉 19pp，说明这个游戏的容错极低。"
   ⇒ 0.01（≈3%/回合）落在"2% 无代价、5% 显著有害"之间，偏保守。
   **而且我们的扰动更轻**：那次是"类和位置都均匀随机"的乱走；本方案**只随机类、
   位置仍由搜索做价值排序** ⇒ 走出的仍是"该类下说得过去的动作"，对局伤害应低于同率的乱走。

### 待定：anchor（用户提出要试）

**这不是普通调参，它决定这个改动有没有效果**：随机钉类产生的目标全落在那 23 个
"从不被使用"的通道上，而那些通道的 **anchor 目标就是它们的旧原值** ⇒ **anchor 对它们是阻力
而不是正则**。不过按 Phase 2 的校准（λ=30 ≈ 有效 anchor/CE 仅 **1%**），CE 应压倒 anchor
约 100:1，所以 λ=30 大概率不挡路 ⇒ 这个 A/B 真正回答的是"**anchor 还有没有在做有用的事**"。

**测法**（训练只要几分钟）：**采集 1 次（带随机钉类）→ 同一份数据训 2 次：λ=0 与 λ=30**。

- 读 (a) 新通道的目标 CE 降不降；(b) 镜像判据 vs 第 0 轮（闪电通道有没有退化）；
- λ=0 ≈ λ=30 ⇒ **anchor 可去掉**（少一个超参）；λ=0 明显更差 ⇒ 保留。

**方法论提醒（原实验记录）**：评估是**完全确定性**的（temperature=0、固定 seed、rng 按 seed
定死）⇒ **重跑不会有任何变化，降噪只能加 seed 数、不能重跑**；判据必须同 seed 配对。
镜像台本就同 seed 配对且对照臂 SE=0，满足这条（要看更多 seed 就调 `--pairs`）。

## 9. 风险 / 待定（原）

- **状态分布偏移**：注入的动作会被**真的执行**，所以对局会偏离"部署时策略会走的路"。
  p 太大 ⇒ 位置网学到的是"不会出现的局面上的位置"。**建议 p 从 0.05（回合级 ~14%）起**，
  按位置样本量与实际状态偏移权衡。
- **共享骨干被稀释**：23 个新通道的目标会一起塑造骨干，可能**伤到闪电通道** ⇒ 判据 3 就是
  盯这件事的。
- **anchor 反向作用**（§4）；λ 可能需要下调。
- **当前无近期收益**：其余 23 个通道**现在不被策略使用**（类头锁死闪电）⇒ 对部署强度
  当前价值≈0；这是**为"以后修类头"铺路** + 更丰富的局面/状态多样性。
- **待定（需用户拍）**：
  1. 随机粒度：**按头**（本文默认，符合"每个头独立决策"）还是按回合（三头一起换）；
  2. p 的初值（建议 0.05）；
  3. anchor 是否同时放松（λ=30 → 10？）。
