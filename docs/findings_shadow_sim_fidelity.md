# 发现：亚军的"影子模拟器"和真实对局对得上吗？

> 2026-10-21。脚本：`code/my_ai/distill_top2/check_shadow_sim_fidelity.py`
> 背景：亚军的 rollout 不跑真实引擎，而是跑一个专门的轻量前向模型 `rs::DefenseSimulator`
> （`antgame_cpp_sdk/include/antgame_sdk/random_search_baseline.hpp`，5,015 行）。

## 0. 结论

**粗对得上，但远不精确。**

- ✅ **重放层面**：真实引擎能逐字段复现真实对局（6/6 抽样回合一致）；
- ⚠️ **预测层面**：影子模拟器的「8 回合期望」与真实引擎的「8 回合实际结果」
  只有 **ρ ≈ 0.35** 的相关；影子自身的可信度上限 **0.86** ⇒ **归一化保真度 ≈ 0.46**；
- ⚠️ **绝对偏差** 从 −370 到 +195 大幅波动；**top-1 一致只有 1/8**。

## 1. 怎么测的

1. 用日志里双方真实下发的 ops + 种子，在真实引擎（pybind `native_game`）里**重放整局**，
   并在 r=0/50/100/200/300/400 与 dump 对账（hp/coins/塔数/蚁数）⇒ **全部一致**，证明基准可靠。
2. 在某些回合同一批候选计划（亚军自己的 40 个），分别：
   - **影子模拟器**：`dump_plan_prior.exe --mode score_ops`，8 回合 rollout 取均值，
     **扣掉 `c1_bonus`**（真实引擎那侧没有这一项）与 `heuristic`（那是选择规则不是估值）；
   - **真实引擎**：clone → 应用该计划的 ops → `advance_round()` × 8 → Python 版 `evaluate_terminal`。
3. 比较两者：Spearman、top-1 是否一致、偏差、以及**可信度上限**
   （同候选、不同 rollout 种子的两次独立采样之间的相关）。

## 3. 为什么它会偏

影子模拟器的三个刻意简化，恰好都是"未来"的主要来源：

1. **rollout 时 `ignore_enemy_spawns = true`** ⇒ **完全不生成后续敌人**。
   真实对局里 8 回合会再出一批蚁，而它们造成的伤害**恰恰取决于你造了什么塔** ⇒
   真实离散度（322）远大于影子（73）就是这个原因。
2. **单边模型**：对手只剩 `generation_level` / `ant_level` 两个标量，不模拟对手的建造/决策。
3. **移动/战斗简化**：只有 top-5「重要蚁」走全量路径，其余用 `move_option_limit` 截断。

## 4. 但它为什么还是赢了

1. **只用于同状态内比较** ⇒ 偏差的**共模部分不影响排序**（只有随候选变化的那部分有害）；
2. **决策规则有强正则**：hold +80 的阈值 + 实测 82% 的决策就是不动
   ⇒ 近似误差在大多数回合根本不进入决策；
3. **真值本身也是代理**：`evaluate_terminal` 也只是"赢"的启发式代理，
   所以"影子 vs 真实引擎"是**代理对代理**，不能等同于"好 vs 坏"；
4. 它给赢家 ~700 次采样（SE≈4），远比我这次的 128 次稳。

## 5. 对我们的意义

- **要复现它的决策**：必须复刻这个近似模型（已复刻，对齐 209/209 候选、heuristic diff = 0）。
- **要超过它**：不该在"8 回合近似期望"上跟它比精度，而应在**前瞻质量**上超过它 ——
  我们的 M6c 用完整引擎 + 长 playout，在这个维度上**严格更优**（代价是慢约 10 倍，
  但我们的候选数 ~24/节点，可以用更少采样）。
- **一个明确的攻击点**：它最大的近似误差源是"不模拟后续敌人 spawn"。
  任何"考虑后续波次"的评估都能在这个维度上优于它。
