# 坍缩模型（46.9%）反而强于健康模型（29.7%）——悖论与假设（2026-09-12）

## 事实

2026-08-11/12 的 az 线（`az_train.py --tau 50 --label-scale 6`）实测过 vs rule_v4 43-47%
（`docs/az_training_validation_results.md` §12/§13）。但 §20 已确认：**batch 30-35 起特征
提取器完全坍缩**（`spatial_feat` 跨样本 std = 0，棋盘信息全丢），文档据此把 43-47% 称为
"**纯 stats 策略的天花板**"。

本次直接复测各 checkpoint 的坍缩状态（`_tmp_check_collapse.py`，128 个真实局面，
指标 = `spatial_feat` 跨样本 std，与 §20 同）：

| checkpoint | cross-sample std | 状态 | 用途 |
|---|---|---|---|
| `az_fixed/gen0120_bn_init` | 0.0784368 | 健康 | 当前线起点 |
| **`az_fixed/az_r10`** | **0.1298745** | **健康** | **当前所有臂用的策略** |
| `az_cpp/az_r69` | **0.00000000** | **完全坍缩** | 历史 46.9% |

## 悖论

**棋盘盲的坍缩模型（46.9%）明显强于棋盘健康的当前模型（29.7%）**——同协议
（256 迭代/深度 4/C++ 引擎）。

也就是说：**当年为了"修好坍缩"而做的冻结骨干等改动，并没有换来棋力**；反而我们
现在比"退化到只看 stats"的当年更差。

## 假设

**H1（先验有害）**：当前策略 `az_r10` 的 priors 尖锐但方向不对（`raw=0%`：无搜索时
全败）。256 次搜索被错误的先验引偏 → 反而不如**均匀先验**（= 坍缩模型的常数策略）
那种"广泛探索、纯价值驱动"的搜索。

- 支持：文档 §"搜索强度 = 价值引导主导，退化策略被 tau=50 价值补偿"——当年的搜索
  本质上是**纯价值驱动**的
- 可测：把当前模型的策略先验**人为抹平**（action_map/head_logits 置常数）再打
  rule_v4，若胜率上升 → H1 成立

**H2（价值配方更好）**：当年的价值头是 `tau=50 + label_scale 6 + --value-passes 3`
（每 epoch 曝光 300%），训练在 213K 的 az `data` 池上；与我们现在的
`terminal + 冻结骨干 + value_warmup + 336 局` 差异巨大。46.9% 可能主要来自**价值头**，
而不是"策略塌成常数"这个副作用。

- 可测：重测 `az_mix_r69p_v50v`（已排队 `refeval_r69_history`）。若今天仍 ~47%，H2
  权重上升，下一步应复原当年那套价值配方

**H3（评估/引擎漂移）**：当年的 46.9% 是 32 局测的，可能本身就是噪声/环境产物。

## 为什么这个悖论重要

前面一整轮工作（池化、tau、kgeo、stats-only）**全部在"健康骨干 + 冻结 + value_warmup"
这套流水线里做**，绝对水平都在 15-31%。而历史上的相对参照（46.9%）来自**另一套已经
被判为"退化"的流水线**。

**如果 H1/H2 成立，那么这些杠杆全都是在一条更差的流水线上做优化**——真正该做的
是先把流水线拉回历史水平，再谈标签/池化的微调。

## 下一步

   64 局同协议 → 分辨 H3（若 ~30% 则当年是噪声）
